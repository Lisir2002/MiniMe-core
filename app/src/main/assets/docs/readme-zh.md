# MiniMe-core

MiniMe-core 是一款运行在 Android 设备上的 AI 代码编辑器，把终端、浏览器、Git 与 AI 助手整合进同一个口袋工作区。

## 项目简介

MiniMe-core 面向移动开发者，目标是在手机与平板上提供接近桌面端的编码体验。它内置 Linux 终端容器、代码浏览与查看器、AI 对话助手，并支持接入多种大模型服务，让你在移动设备上也能完成编辑、调试与提交。

## 核心功能

- **AI 对话**：接入多家大模型服务商（OpenAI、Anthropic、DeepSeek、Gemini、豆包、Moonshot、MiniMax、Qwen、智谱等），支持自定义 Prompt 与多会话管理。
- **容器终端**：基于 Termux 终端会话，提供完整的 shell 环境，支持前后台保活。
- **内置浏览器**：集成 WebView 浏览器内核，可在应用内打开网页与文档。
- **MCP 工具**：支持 Model Context Protocol，可扩展 AI 助手的工具与技能。
- **Git**：内置 Git 页面，支持仓库浏览、提交与远程服务器管理。
- **代码查看器**：在线浏览 GitHub 仓库源码，支持语法高亮、大纲与搜索。
- **代理内核**：集成 mihomo 代理内核，可配置混合端口与规则。

## 快速开始

1. 下载并安装最新版本的 MiniMe-core。
2. 首次启动后，前往「设置」配置你的 AI 服务商与 API Key。
3. 如需终端能力，在「核心组件」中初始化终端容器。
4. 打开 AI 对话开始提问，或进入代码浏览查看开源仓库源码。
