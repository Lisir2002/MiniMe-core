# MiniMe-core

MiniMe-core is an AI code editor that runs on Android devices, bringing together a terminal, a browser, Git, and an AI assistant into a single pocket-sized workspace.

## About

MiniMe-core is built for mobile developers who want a desktop-like coding experience on phones and tablets. It bundles a Linux terminal container, a code browser and viewer, an AI chat assistant, and support for multiple LLM providers, so you can edit, debug, and commit code right from your mobile device.

## Key Features

- **AI Chat**: Connect to many LLM providers (OpenAI, Anthropic, DeepSeek, Gemini, Doubao, Moonshot, MiniMax, Qwen, Zhipu, and more), with custom prompts and multi-session management.
- **Container Terminal**: A Termux-based shell session with foreground/background keep-alive for a full command-line environment.
- **Built-in Browser**: An integrated WebView browser kernel for opening web pages and docs inside the app.
- **MCP Tools**: Supports the Model Context Protocol to extend the AI assistant with tools and skills.
- **Git**: A built-in Git page for repository browsing, commits, and remote server management.
- **Code Viewer**: Browse GitHub repository source online with syntax highlighting, outline, and search.
- **Proxy Core**: An integrated mihomo proxy core with configurable mixed port and rules.

## Quick Start

1. Download and install the latest release of MiniMe-core.
2. On first launch, go to Settings and configure your AI provider and API key.
3. If you need the terminal, initialize the terminal container under Core Components.
4. Open AI Chat to start asking questions, or browse source code in the code viewer.
