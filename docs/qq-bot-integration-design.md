# MiniMe-core QQ 机器人对接设计文档

> 版本：v1.0-draft
> 状态：设计阶段
> 最后更新：2026-09-27

## 一、概述

### 1.1 项目目标

将 MiniMe-core 的 AI Agent 能力与 QQ 平台对接，使 Agent 可以作为 QQ 机器人运行，接收 QQ 消息并通过 AI 生成回复。

### 1.2 核心思路

采用 **方案 A：MiniMe-core 内置 OneBot 11 反向 WebSocket 服务端 + 终端容器内运行 LLBot**。

```
QQ 用户 → LLBot（协议端，无头模式）→ OneBot 11 反向 WS → MiniMe-core Agent → 回复 → LLBot → QQ
```

### 1.3 技术选型

| 组件 | 选型 | 说明 |
|------|------|------|
| 协议端 | LLBot（LuckyLilliaBot）无头模式 | 纯协议实现，不依赖 QQ 客户端，Rust 编写，Linux arm64 可运行 |
| 通信协议 | OneBot 11（反向 WebSocket） | 生态最成熟，功能最全，兼容 GoCQ |
| Agent 核心 | MiniMe-core 现有 Agent | 复用已有对话、工具、模型能力 |
| WS 服务端 | Ktor / OkHttp WebSocket | 监听本地回环端口 |
| 运行环境 | MiniMe-core 终端容器（Proot/Linux） | LLBot 在容器内运行 |

## 二、可行性分析

### 2.1 LLBot 在 Android 容器内运行

| 维度 | 可行性 | 说明 |
|------|--------|------|
| Node.js 运行时 | 可行 | 容器内可安装 Node.js，LLBot CLI 版基于 Node.js |
| Rust 纯协议版 | 可行 | LLBot 无头模式为 Rust 实现，提供 Linux arm64 二进制 |
| PMHQ 有头模式 | 不可行 | 需要 NTQQ 客户端，Android 容器内无法运行桌面 QQ |
| 网络 | 可行 | 容器共享主机网络，本地回环通信无延迟 |
| 文件系统 | 可行 | 容器内可读写，图片/语音缓存有存储位置 |
| 后台保活 | 难点 | Android 后台限制，需前台服务 + 通知栏常驻 |
| 内存占用 | 可接受 | LLBot 约 100-200MB，Agent 约 300MB，合计 500MB+ |

**结论**：使用**无头模式（纯协议 Rust 版）**，轻量稳定，不依赖 QQ 客户端。

### 2.2 OneBot 11 反向 WS 服务端

MiniMe-core 为 Kotlin/Compose 应用，内置 WebSocket 服务端无技术障碍：
- 监听本地端口（默认 3001）
- LLBot 配置反向 WS 指向 `ws://127.0.0.1:3001`
- 纯本地通信，不涉及公网暴露
- 复用项目已有网络层基础

│                        │       ↓                    │    │

│                        │       ↓                    │    │
│                        │  触发引擎（TriggerEngine）   │    │
│                        │       ↓                    │    │

│                        │       ↓                    │    │

│                        └────────────────────────────┘    │
│                                                          │
│  ┌──────────────┐                                       │

### 3.2 核心模块

| 模块 | 职责 |
|------|------|
| QQBotService | 后台服务，管理 LLBot 进程生命周期 + WebSocket 服务端 |
| OneBot11Server | WebSocket 服务端，解析 OneBot 11 协议消息，调用 API 发送消息 |
| MessageMapper | OneBot 消息段 ↔ Agent 消息格式双向转换 |
| SessionManager | 按 QQ 号/群号维护独立会话上下文 |
| TriggerEngine | 触发规则判断（@机器人 / 私聊 / 关键词 / 权限） |
| ReplyFormatter | Agent 回复 → OneBot 消息段格式化 |
| GroupManager | 群管理功能（禁言/踢人/审批/欢迎/违禁词等） |
| QQBotSettings | 设置页面（QQ号配置、触发规则、权限、LLBot管理、群管理） |

## 四、消息流设计

### 4.1 接收消息流

```
LLBot 收到 QQ 消息
  → 反向 WS 推送给 MiniMe-core（JSON）
  → OneBot11Server 解析协议
  → MessageMapper 转换消息格式
  → TriggerEngine 判断是否触发
  → SessionManager 获取/创建会话
  → Agent 调度器调用 agent.chat()
  → 等待 AI 回复
  → ReplyFormatter 格式化回复
  → OneBot11Server 调用 send_group_msg / send_private_msg
  → LLBot 发送到 QQ
```

### 4.2 消息格式转换

#### OneBot → Agent（输入）

| OneBot 消息段 | Agent 消息 | 处理方式 |
|--------------|-----------|---------|
| text | 文本 | 直接传递 |
| image | 图片 | 下载到本地缓存，作为多模态输入 |
| at | @提及 | 过滤@机器人部分，保留@其他人 |
| reply | 引用回复 | 提取被引用消息作为上下文 |
| face | QQ表情 | 转为文字描述或忽略 |
| record | 语音 | 暂不支持（后续可加语音识别） |
| video | 视频 | 暂不支持 |

#### Agent → OneBot（输出）

| Agent 输出 | OneBot 消息段 | 处理方式 |
|-----------|--------------|---------|
| 文本 | text | 直接发送，超长自动分段 |
| 图片 | image | 上传到 QQ（LLBot 处理） |
| 代码块 | text | 保留代码格式 |
| Markdown | text | 转为纯文本 |
| 工具调用结果 | text | 格式化后发送 |

## 五、会话与上下文管理

### 5.1 会话隔离规则

| 场景 | 会话 Key | 说明 |
|------|---------|------|
| 私聊 | `qq_{user_id}` | 每个 QQ 用户独立会话 |
| 群聊（默认） | `group_{group_id}_{user_id}` | 群内每人独立会话 |
| 群聊（共享模式） | `group_{group_id}` | 整个群共享一个会话 |

### 5.2 上下文策略

| 策略 | 说明 | 默认值 |
|------|------|--------|
| 上下文长度 | 保留最近 N 条消息 | 20 条 |
| 会话超时 | 超过 N 小时无消息自动清理 | 2 小时 |
| 手动重置 | 用户发送"/reset"清除 | 支持 |
| 群模式 | 每用户独立 / 群共享 | 每用户独立 |

### 5.3 多模型支持

- 每个 QQ 号/群可配置不同默认模型
- 支持通过指令切换模型（如 `/model gpt-4o`）
- 复用 MiniMe-core 已有模型供应商配置

## 七、权限与安全

### 7.1 用户角色层级

| 角色 | 说明 | 能力 |
|------|------|------|
| 主人 | 配置的 QQ 号 | 全部权限 |
| 管理员 | 群管理员 / 自定义 | 禁言、踢人、审批、配置、切换模型 |
| 信任用户 | 自定义 | 可使用 agent 工具（终端/浏览器/MCP） |
| 普通成员 | 默认 | 基础 agent 对话 |
| 受限用户 | 自定义 | 只能触发关键词回复，不能 agent 对话 |
| 黑名单 | 自定义 | 完全忽略 |

### 7.2 工具调用安全（核心）

**默认原则：QQ 机器人仅开放纯对话能力，工具调用需显式授权。**

| 工具 | 风险 | 默认权限 | 可授权给 |
|------|------|---------|---------|
| 终端命令执行 | 任意用户可控制手机终端 | 禁用 | 信任用户+ |
| 浏览器 | 访问内网、消耗流量 | 禁用 | 信任用户+ |
| MCP 工具 | 取决于具体 MCP 服务 | 禁用 | 按工具粒度配置 |
| 文件操作 | 读写手机文件 | 禁用 | 管理员+ |
| 代码执行 | 执行任意代码 | 禁用 | 管理员+ |

### 7.3 防滥用机制

- 速率限制：每用户每分钟最多 N 条消息（默认 10 条）
- 并发限制：同时最多 N 个会话在生成（默认 3 个）
- 内容过滤：敏感词过滤（可选）
- 日志审计：所有 QQ 消息和回复记录日志

## 八、LLBot 集成与管理

### 8.1 部署方式

| 方式 | 说明 | 推荐度 |
|------|------|--------|
| 内置容器运行 | MiniMe-core 终端容器内自动下载/启动 LLBot | 推荐 |
| 外部运行 | 用户在电脑/服务器跑 LLBot，反向 WS 连手机 | 备选 |

### 8.2 内置 LLBot 管理功能

在 QQ 机器人设置页面提供：
- 一键下载 LLBot（对应架构的二进制）
- 启动/停止/重启 LLBot
- 查看 LLBot 运行日志
- QQ 号登录管理（扫码 / 快速登录）
- 开机自启选项
- 前台服务保活（通知栏常驻）

### 8.3 配置自动生成

MiniMe-core 自动生成 LLBot 配置文件，用户无需手动配置：

```json5
{
  "webui": { "enable": false },
  "ob11": {
    "enable": true,
    "connect": [{
      "type": "ws-reverse",
      "enable": true,
      "url": "ws://127.0.0.1:3001/onebot/v11/ws",
      "token": "<自动生成>",
      "reportSelfMessage": false,
      "messageFormat": "array"
    }]
  },
  "onlyLocalhost": true,
  "log": true
}
```

## 九、QQ 群管理功能

### 9.1 群管理核心能力（基于 OneBot 11）

| 功能 | API | 说明 |
|------|-----|------|
| 群成员列表 | `get_group_member_list` | 获取所有群成员 |
| 群成员信息 | `get_group_member_info` | 昵称、等级、权限、入群时间 |
| 群信息 | `get_group_info` | 群名、成员数 |
| 禁言 | `set_group_ban` | 禁言/解禁，可设时长 |
| 全员禁言 | `set_group_whole_ban` | 开启/关闭全员禁言 |
| 踢人 | `set_group_kick` | 移出群成员，可选拒绝再加群 |
| 群名片 | `set_group_card` | 修改成员群昵称 |
| 管理员设置 | `set_group_admin` | 设置/取消管理员 |
| 退群 | `set_group_leave` | 机器人主动退群 |
| 精华消息 | `set_essence_msg` | 设置/取消精华 |
| 群文件 | `get_group_file_list` | 群文件管理 |
| 入群事件 | `group_increase` | 新成员入群通知 |
| 退群事件 | `group_decrease` | 成员退群通知 |
| 加群请求 | `group_request` | 加群申请审批 |
| 管理员变更 | `group_admin` | 管理员设置/取消事件 |

### 9.2 每群独立配置

每个群存储独立配置（GroupConfig）：

```
GroupConfig
├── 基础设置：群名缓存、机器人昵称、启用/禁用、欢迎消息
├── 触发规则：触发方式、关键词前缀、忽略关键词
├── 模型配置：默认模型、上下文长度、群专属系统提示词、参数
├── 权限配置：工具可用角色、触发角色、黑名单
├── 群管理：自动审批、自动欢迎、违禁词检测、刷屏检测、定时消息
└── 数据统计：消息数、响应数、活跃用户
```

### 9.3 群自动化功能

#### 新成员欢迎
- 触发：`group_increase` 事件
- 可配置欢迎语模板（支持 `{user_name}` `{group_name}` 变量）
- 可选 @新成员、发送群规

#### 加群自动审批
- 策略：自动通过 / 匹配关键词通过 / 自动拒绝 / 手动审批
- 手动审批：转发管理员，回复"通过"/"拒绝"
- 记录审批日志

#### 违禁词检测
- 内置词库 + 自定义词库 + 正则匹配
- 处理方式：仅警告 / 撤回 / 禁言（时长可配） / 踢人 / 通知管理员

#### 刷屏检测
- 检测维度：短时间消息数、重复消息、长文本
- 惩罚梯度：警告 → 禁言10分钟 → 禁言1小时

#### 定时消息
- 支持每天/每周/每月/间隔周期
- 内容：文本/图片/混合
- 可配置目标群（单个或多个）

#### 关键词自动回复
- 触发：精确匹配 / 模糊匹配 / 正则
- 回复：文本/图片/混合
- 支持优先级排序

### 9.4 群权限矩阵

| 操作 | 群主 | 管理员 | 信任用户 | 普通成员 | 受限 |
|------|------|--------|---------|---------|------|
| agent 对话 | ✓ | ✓ | ✓ | ✓ | ✗ |
| 工具调用 | ✓ | ✓ | ✓ | ✗ | ✗ |
| 切换模型 | ✓ | ✓ | ✗ | ✗ | ✗ |
| 禁言/踢人 | ✓ | ✓ | ✗ | ✗ | ✗ |
| 修改群配置 | ✓ | ✓ | ✗ | ✗ | ✗ |
| 加群审批 | ✓ | ✓ | ✗ | ✗ | ✗ |
| 查看统计 | ✓ | ✓ | ✗ | ✗ | ✗ |

### 9.5 群管理指令

| 指令 | 功能 | 权限 |
|------|------|------|
| `/信任 @用户` | 设为信任用户 | 管理员+ |
| `/受限 @用户` | 设为受限 | 管理员+ |
| `/拉黑 @用户` | 加入黑名单 | 管理员+ |
| `/解禁 @用户` | 移除黑名单 | 管理员+ |
| `/禁言 @用户 10m` | 禁言指定时长 | 管理员+ |
| `/踢人 @用户` | 移出群 | 管理员+ |
| `/统计` | 查看群统计 | 管理员+ |

### 9.6 与 Agent 协同

- **Agent 辅助管理**：自然语言指令，如"把刚才发广告的人禁言10分钟"
- **智能群规**：Agent 判断消息是否违规，给出处理建议
- **自动群聊总结**：每日自动生成群聊摘要
- **问答知识库**：常见问题自动回复，不消耗 agent 调用

## 十一、风险与挑战

| 风险 | 严重度 | 应对措施 |
|------|--------|---------|
| Android 后台杀死 LLBot 进程 | 高 | 前台服务 + 通知栏常驻 + 自动重启机制 |
| QQ 封号风控 | 高 | 无头模式有风险，明确提示用户；限速限频；避免敏感操作 |
| 内存占用过大 | 中 | LLBot + Agent 合计 500MB+，低端机告警；支持外部 LLBot 模式 |
| 工具调用安全 | 高 | 默认禁用工具，按用户角色授权 |
| 消息延迟 | 中 | 本地回环延迟低，Agent 生成为主要延迟 |
| LLBot 版本更新 | 低 | 内置更新检查 |
| 多 QQ 号资源消耗 | 中 | 每号独立 LLBot 实例，提示资源消耗 |

## 十二、实施路线

| 阶段 | 内容 | 核心交付 |
|------|------|---------|
