# MiniMe UI 设计规范

> 版本：1.0.0
> 状态：生效中
> 最后更新：2026-09-27

本规范为 MiniMe-core 项目所有页面的 UI 设计硬性约束，新增页面必须遵守，已有页面逐步迁移。

---

## 1. 页面槽位设计

### 1.1 标准页面结构

所有页面遵循统一的槽位布局：

```
┌─────────────────────────────────────┐
│  ← 页面标题            [操作按钮]    │ ← 顶栏（唯一，页面级操作放 actions）
├─────────────────────────────────────┤
│  [全部] [分类A] [分类B] ...         │ ← Tab 栏（可选，顶栏下方固定）
├─────────────────────────────────────┤
│  统计卡片 / 筛选器 / 说明文字       │ ← 内容头部（随内容滚动）
├─────────────────────────────────────┤
│                                     │
│  内容区（LazyColumn / 可滚动）      │
│                                     │
├─────────────────────────────────────┤
│  [底部操作按钮] 或 [FAB]            │ ← 底部操作区（可选）
└─────────────────────────────────────┘
```

### 1.2 核心规则

| 规则 | 说明 |
|------|------|
| **顶栏唯一** | 每个页面只有一个顶栏，由外层 Scaffold/NavHost 提供。页面内部禁止再创建 Row 模拟顶栏操作行。 |
| **页面级操作放顶栏** | 搜索、溢出菜单、添加、刷新等按钮，统一放顶栏右侧 actions 区域。 |
| **搜索模式：顶栏内联** | 点击搜索图标后，顶栏标题区域切换为搜索输入框 + 清除按钮，搜索关闭后恢复标题。不采用顶栏下方展开搜索栏的方式。 |
| **Tab 固定位置** | 有分类 Tab 的页面，Tab 栏固定在顶栏下方，不随内容滚动。 |
| **内容头部可滚动** | 统计卡片、筛选器、说明文字等放在内容区顶部，随内容一起滚动。 |
| **底部操作** | 主要操作按钮放底部固定栏或 FAB，不放内容区底部。 |

### 1.3 顶栏内联搜索规范

```
正常模式：
┌─────────────────────────────────────┐
│  ← 页面标题        [搜索] [更多]    │
└─────────────────────────────────────┘

搜索模式（点击搜索图标后）：
┌─────────────────────────────────────┐
│  ← [搜索输入框............] [×]    │
└─────────────────────────────────────┘
```

- 点击搜索图标：顶栏标题替换为 `TextField`，自动聚焦，弹出键盘
- 输入框左侧保留返回箭头（点击退出搜索模式，清除输入）
- 输入框右侧清除按钮（点击清空输入，不退出搜索模式）
- 退出搜索模式：恢复正常顶栏，清除搜索关键词，列表恢复全量
- 搜索过程中 Tab 和内容区保持可见，实时过滤结果

### 1.4 顶栏 actions 排列规则

- 最多显示 2 个图标按钮，其余放入溢出菜单（MoreVert）
- 优先级：搜索 > 添加 > 刷新 > 其他
- 溢出菜单项必须有图标 + 文字
- 危险操作（删除/清空）在溢出菜单中用 error 色文字

## 2. 组件使用规范

### 2.1 统一组件

| 组件 | 使用场景 | 禁止替代 |
|------|----------|----------|
| `AppCard` | 所有卡片容器 | 禁止直接用 Material3 Card |
| `AppButton` | 主要/次要按钮 | 禁止直接用 Material3 Button |
| `AppChip` | 标签/筛选 | 禁止直接用 Material3 Chip |
| `AppSegmentedControl` | 分类 Tab/分段选择 | 禁止自定义 Tab 行 |
| `AppTopAppBar` | 页面顶栏 | 禁止自定义 Row 模拟顶栏 |
| `AppSectionHeader` | 分组标题 | 禁止直接用 Text 加粗 |
| `AppStatusDot` | 状态指示点 | 禁止用 Text("●") 模拟 |

### 2.2 颜色规范

- 所有颜色必须通过 `MaterialTheme.colorScheme` 获取
- 禁止硬编码颜色值（#FF0000 等）
- 自定义颜色必须在 Theme 中定义，通过 colorScheme 扩展
- 成功/错误/警告分别用 `primary`/`error`/`tertiary` 或对应 Container 色

### 2.3 间距规范

- 统一使用 `Spacing` 对象（Spacing.xs/sm/md/lg/xl）
- 禁止硬编码 dp 间距（除特殊圆角/尺寸外）
- 卡片内边距统一 `Spacing.md`
- 卡片间距统一 `Spacing.sm`

### 2.4 字体规范

- 统一使用 `MaterialTheme.typography`
- 标题：titleLarge/titleMedium/titleSmall
- 正文：bodyLarge/bodyMedium/bodySmall
- 标签：labelLarge/labelMedium/labelSmall
- 禁止硬编码 fontSize

## 3. 列表与卡片规范

### 3.1 列表项结构

```
┌─────────────────────────────────────┐
│ ● 标题（加粗）            时间      │
│ [分类标签]                          │
│ 描述文字（次级颜色，最多2行）       │
└─────────────────────────────────────┘
```

- 左侧状态指示点（成功=绿色，失败=红色，用 AppStatusDot）
- 标题行：标题 + 右对齐时间
- 分类标签：AppChip，带图标
- 描述：onSurfaceVariant，最多2行，超出省略

### 3.2 按日期分组

- 列表按日期分组，组标题显示"9月26日 星期五"
- 今天的事件显示"今天"，昨天显示"昨天"
- 组内卡片间距 Spacing.xs，组间距 Spacing.md

### 3.3 空/错/加载状态

- 加载中：居中 CircularProgressIndicator
- 空状态：居中图标 + 标题 + 副标题说明
- 错误状态：居中错误图标 + 错误信息 + 重试按钮
- 禁止空白页面

---

## 4. 字符串规范

- 所有用户可见文字必须走 `strings.xml`
- 中英文同步维护
- 字符串命名语义化：`settings_zth_tier_disabled`，禁止 hash 命名（`ui____0f215ee0`）
- 禁止硬编码中文字符串在代码中

---

## 5. 禁止事项

- 禁止页面内创建第二个顶栏/操作行
- 禁止硬编码颜色、字体、间距
- 禁止使用 emoji
- 禁止 hash 命名的字符串资源
- 禁止直接用 Material3 基础组件替代项目统一组件
- 禁止搜索栏在顶栏下方展开（必须顶栏内联）

---

## 6. 迁移计划

已有页面逐步迁移到本规范，优先级：
1. 操作审计页面（立即）
2. ZTH 设置页面
3. 高级设置页面
4. 安全设置页面
5. 其他设置子页面

新增页面必须从第一版就遵守本规范。
