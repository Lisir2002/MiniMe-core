# MiniMe-core 隐私政策

**最后更新日期：2026年9月27日**

MiniMe-core（以下简称"本软件"）重视用户隐私。本隐私政策说明本软件如何收集、使用、存储和保护您的信息。

## 一、信息收集

本软件遵循"最小必要"原则，尽可能减少数据收集：

### 1.1 本地存储的信息（不上传）

以下信息仅存储在您的设备本地，不会上传至任何服务器：

- **对话记录**：您与 AI 的对话内容、消息历史
- **配置信息**：模型供应商配置、API Key、偏好设置
- **凭据信息**：SSH 密钥、远程连接配置、备份加密密钥
- **终端历史**：终端命令历史、容器配置
- **技能数据**：自定义技能、MCP 配置
- **日志文件**：应用运行日志、崩溃日志（仅本地）

### 1.2 传输至第三方的信息

使用以下功能时，相关信息会传输至对应第三方服务：

- **AI 对话**：您的对话内容会传输至您配置的 AI 模型供应商服务器
- **Git 操作**：Git 相关操作会与您配置的 Git 托管平台通信
- **内置浏览器**：浏览器访问的网页内容由对应网站处理
- **远程连接**：SSH/SFTP 连接会与您配置的远程服务器通信

本软件不会将上述信息传输至开发者的服务器。

### 1.3 不收集的信息

本软件不收集以下信息：

- 您的姓名、电话、邮箱等个人身份信息
- 您的位置信息
- 您的通讯录、相册等设备数据
- 您的设备唯一标识符（用于追踪）

## 二、信息使用

### 2.1 本地信息的使用

本地存储的信息仅用于：

- 提供软件核心功能（AI 对话、代码编辑、终端等）
- 保存您的偏好设置和配置
- 应用崩溃时的问题排查（仅本地日志）

### 2.2 第三方信息的使用

传输至第三方的信息由对应第三方按照其隐私政策处理，本软件不对第三方的数据处理行为负责。建议您在使用前阅读相关第三方的隐私政策。

## 三、信息存储与保护

### 3.1 加密存储

- 所有本地数据库采用 SQLCipher 全库加密（AES-256）
- API Key、SSH 密钥等敏感字段采用二级加密（V2 AES-GCM）
- 加密主密钥（DEK）由 Android Keystore 硬件保护（如设备支持）

### 3.2 数据安全措施

- 应用无 Root 权限，无法访问其他应用数据
- 敏感操作（凭据查看、主密钥重置）需要生物识别或应用锁验证
- 防截图录屏功能可配置，防止敏感页面被恶意截取
- 备份文件支持加密导出

### 3.3 数据删除

- 您可以随时在应用内清除对话记录、配置和缓存
- 卸载应用将删除所有本地数据
- 已传输至第三方的数据，需按照第三方的流程申请删除

## 四、信息共享

本软件不会向任何第三方出售、出租或共享您的个人信息。以下情况除外：

1. **您明确同意**：在您明确授权的情况下
2. **法律要求**：根据法律法规或政府主管部门的要求
3. **服务提供**：为实现软件功能，与 AI 模型供应商等必要第三方的通信

## 五、儿童隐私

本软件不面向 13 岁以下儿童设计。如果您是儿童，请在监护人指导下使用本软件。

## 六、您的权利

您对自己的数据享有以下权利：

1. **访问权**：您可以在应用内查看所有本地存储的数据
2. **删除权**：您可以随时删除任何本地数据
3. **导出权**：您可以导出备份数据
4. **控制权**：您可以随时关闭防截图、崩溃上报等功能

## 七、政策变更

1. 本隐私政策可能随软件功能更新而调整
2. 重大变更将在应用更新时显著提示
3. 继续使用更新后的软件，即视为同意变更后的政策

## 八、联系我们

如对本隐私政策有任何疑问，可通过 GitHub 仓库提交 Issue 与开发者联系。
