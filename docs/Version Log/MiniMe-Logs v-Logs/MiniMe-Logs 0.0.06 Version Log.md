# MiniMe-Logs 0.0.6 Version Log

> MiniMe Logs 附属应用全面体验升级版本：长按菜单、设置页、崩溃页三大核心页面深度重构，功能从"可用"升级为"专业"。

**发布日期**：2026-09-24

### 新功能

- 长按菜单全面重构为底部 BottomSheet：图标+分组标题+状态感知，新增只显示/隐藏此Tag、只显示此等级、用消息搜索、分享此行/上下文、跳转时间等操作
- 长按菜单支持双击行快速复制消息内容，长按触发震动反馈
- 设置页新增字体大小（小/中/大/特大）、字体切换（系统默认/Monospace）、显示毫秒、自动尾随、默认文件模式（今天/记住上次/每次询问）、主题切换（跟随系统/浅色/深色/纯黑）全部真正生效
- 崩溃页新增搜索（按异常类型/消息/Tag/堆栈，关键词高亮）、ANR 识别、Native Crash 识别、忽略功能、24h 趋势徽标（恶化/好转/持平）、排序选项（次数/最近时间/首次时间）
- 崩溃详情页新增堆栈语法高亮（异常类型红/类名蓝/方法名粗/Caused by 红）、堆栈行可点击复制、长堆栈横向滚动、发生记录可点击、SAF 导出 .txt 文件、长按多选批量操作、24h 发生时间分布柱状图、相似崩溃提示
- 崩溃已修复/忽略状态持久化，重启不丢失
- 全局数据同步：切换日志目录后所有页面（日志/统计/崩溃）自动刷新，带 shimmer 骨架屏过渡

### 改进

- 等级筛选栏从字母缩写+分离计数改为完整名称（Error/Warn/Info/Debug/Verbose）+计数合并进同一 chip
- 崩溃卡片状态指示从 emoji 改为 Material 图标+左侧色条，详情按钮升级为 Filled 主操作
- 崩溃筛选从下拉菜单改为 4-Tab 横向切换（全部/未修复/已修复/已忽略），带实时计数
- 崩溃聚合 key 从"异常类型+堆栈首行（含行号）"改为"异常类型+消息前50字符"，同异常不同行号正确合并

### 修复

- 尾随模式计数不准：异步加载导致 after-before 永远为 0，改为同步加载
- 日志列表排序：最新日志从顶部往下排列
- 长日志内容超出屏幕被截断：消息行支持横向滑动
- 三按钮弹窗中间按钮白底白字看不清：改为 Tonal 按钮
- 软件内版本号写死 1.0.0：改为读取 BuildConfig.VERSION_NAME
- 设置页 9 项摆设功能：移除 12小时制和清理7天前日志，导出项降级为"即将上线"明示，其余 6 项真正实现
- 智能识别主应用日志目录：SAF 选择器预定位到 Documents/MiniMe-core/，错误目录拒绝并引导
