# MiniMe-Logs 0.0.6 Version Log

> MiniMe Logs 附属应用全面体验升级版本：长按菜单、设置页、崩溃页三大核心页面深度重构，功能从"可用"升级为"专业"。

**发布日期**：2026-09-24

### 新功能

- **长按菜单重构**：长按菜单重构为底部BottomSheet，按图标分组展示并支持Tag、等级、分享等操作。
- **双击复制反馈**：支持双击日志行快速复制消息内容，长按时触发震动反馈提升操作手感。
- **设置项全面生效**：字体大小、字体、毫秒显示、尾随、文件模式与主题等设置项全部真正生效。
- **崩溃页增强**：崩溃页新增搜索、ANR与Native Crash识别、忽略、24h趋势徽标及排序选项。
- **崩溃详情增强**：崩溃详情新增堆栈语法高亮、点击复制、导出txt、多选批量操作与时间分布图。
- **崩溃状态持久化**：崩溃的已修复与忽略状态持久化保存，应用重启后不会丢失标记。
- **全局数据同步**：切换日志目录后日志、统计、崩溃页面自动刷新，带骨架屏过渡动画。

### 改进

- **筛选栏样式改进**：等级筛选栏改为完整名称加计数合并至同一标签，信息更直观易读。
- **崩溃卡片改版**：崩溃卡片状态改用Material图标加左侧色条，详情按钮升级为主操作按钮。
- **崩溃筛选改版**：崩溃筛选改为四Tab横向切换，展示全部、未修复、已修复、已忽略及计数。
- **崩溃聚合优化**：崩溃聚合规则改为异常类型加消息前50字符，同异常不同行号正确合并。

### 修复

- **尾随计数修复**：修复尾随模式下新增日志计数始终为零的问题，改为同步加载计数。
- **日志排序修复**：修复日志列表排序，最新日志条目调整为从顶部向下排列展示。
- **长日志截断修复**：修复长日志内容超出屏幕被截断的问题，消息行支持横向滑动查看。
- **弹窗按钮修复**：修复三按钮弹窗中间按钮白底白字看不清的问题，改为Tonal按钮样式。
- **版本号读取修复**：修复应用内版本号写死为1.0.0的问题，改为读取实际构建版本号。
- **设置页功能清理**：清理设置页摆设项，导出项标注即将上线，其余六项功能真正实现。
- **目录智能识别**：SAF选择器预定位到主应用日志目录，选错目录时拒绝并引导用户重选。

### 移除

- **摆设功能移除**：移除设置页12小时制与清理7天前日志两项未实现的摆设功能。
