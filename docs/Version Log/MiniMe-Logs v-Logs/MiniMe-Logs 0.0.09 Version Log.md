# MiniMe-Logs 0.0.9 Version Log

> 日志目录与主应用统一，打开即可看到主应用导出的日志，无需再手动翻找目录。

**发布日期**：2026-10-15

### 改进

- **目录自动对齐**：日志来源新增「下载目录」并设为自动检测首选，与主应用导出目标一致，打开即可读到日志。
- **历史目录兼容**：继续扫描文档目录与应用私有目录，早期导出的日志同样可以查看，不会因换目录丢失。
- **选目录更省心**：手动选择目录时直接定位到主应用日志目录，不必再逐层翻找，选错时的提示也指向正确位置。

### 修复

- **读不到日志**：此前扫描的是文档目录，而主应用实际导出到下载目录，两边不一致导致打开后看不到任何日志。
- **设置兼容**：旧的日志来源设置在新的来源列表中无法识别时会回落为自动检测，避免设置读取异常。
