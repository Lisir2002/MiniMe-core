# MiniMe-Logs 0.0.1 Version Log

> 独立日志查看附属应用首发版本。

**发布日期**：2026-09-23

### 新功能

- **应用首发**：独立日志查看附属应用首次发布，专门用于读取并展示主应用运行日志。
- **主应用日志读取**：支持读取主应用MiniMe-core产生的运行日志文件，供开发者排查问题。
- **日志等级筛选**：提供Error至Verbose五种日志等级筛选，可分级过滤查看不同优先级输出。
- **关键词搜索高亮**：支持关键词全文搜索匹配，命中内容在日志列表中高亮显示。
- **实时尾随模式**：开启尾随模式后日志自动滚动至最新条目，实时跟踪应用运行状态。
