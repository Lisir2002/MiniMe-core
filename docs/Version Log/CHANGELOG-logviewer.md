# Changelog（MiniMe Logs）

本文件记录 MiniMe Logs（日志查看器）的用户可见变更，采用与主应用一致的用户面向格式（见 AGENTS.md 发版规范）。

- 最新版本置顶，倒序排列。
- 日期用 ISO 8601（`YYYY-MM-DD`）。
- 禁止使用 emoji；不写内部术语、类名或实现细节。
- 各版本的详细说明另存于 `MiniMe-Logs v-Logs/MiniMe-Logs {版本} Version Log.md`。

## [0.0.9] - 2026-10-15

日志目录与主应用统一，打开即可看到主应用导出的日志，无需再手动翻找目录。

### 改进

- **目录自动对齐**：日志来源新增下载目录并设为自动检测首选，与主应用导出目标一致，打开即可读到日志。
- **历史目录兼容**：继续扫描文档目录与应用私有目录，早期导出的日志同样可以查看，不会因换目录丢失。
- **选目录更省心**：手动选择目录时直接定位到主应用日志目录，不必再逐层翻找，选错时的提示也指向正确位置。

### 修复

- **读不到日志**：此前扫描的是文档目录，而主应用实际导出到下载目录，两边不一致导致打开后看不到任何日志。
- **设置兼容**：旧的日志来源设置在新的来源列表中无法识别时会回落为自动检测，避免设置读取异常。

## [0.0.8] - 2026-09-25

同步主应用组件体系与主题命名，优化代码架构，提升长期可维护性。

### 改进

- **主题体系统一**：主题组件命名与主应用保持一致，组件体系统一规范。
- **架构细节优化**：应用架构细节优化，提高产品质量，优化用户体验。

## [0.0.7] - 2026-09-25

### 改进

- **应用图标更新**：应用图标替换为日志监控主题设计，多分辨率适配各设备显示一致。

### 移除

- **旧版图标移除**：移除旧版自适应矢量图标定义，停用前景背景矢量分离的图标模式。

## [0.0.6] - 2026-09-24

附属应用全面体验升级：长按菜单、设置页、崩溃页三大核心页面深度重构，功能从可用升级为专业。

### 新功能

- **长按菜单重构**：长按菜单改为底部弹层，按图标分组展示并支持 Tag、等级、分享等操作。
- **双击复制反馈**：双击日志行快速复制内容，长按时触发震动反馈提升操作手感。
- **设置项全面生效**：字体大小、字体、毫秒显示、尾随、文件模式与主题等设置项全部真正生效。
- **崩溃页增强**：崩溃页新增搜索、无响应与原生崩溃识别、忽略、趋势徽标及排序选项。
- **崩溃详情增强**：崩溃详情新增堆栈高亮、点击复制、导出、多选批量操作与时间分布图。
- **崩溃状态持久化**：崩溃的已修复与忽略状态持久化保存，重启后不会丢失标记。
- **全局数据同步**：切换日志目录后各页面自动刷新，带骨架屏过渡动画。

### 改进

- **筛选栏样式改进**：等级筛选栏改为完整名称加计数合并至同一标签，信息更直观易读。
- **崩溃卡片改版**：崩溃卡片状态改用 Material 图标加左侧色条，详情按钮升级为主操作按钮。
- **崩溃筛选改版**：崩溃筛选改为四个横向标签切换，展示全部、未修复、已修复、已忽略及计数。
- **崩溃聚合优化**：崩溃聚合规则改为异常类型加消息前 50 字符，同异常不同行号正确合并。

### 修复

- **尾随计数修复**：修复尾随模式下新增日志计数始终为零的问题，改为同步加载计数。
- **日志排序修复**：修复日志列表排序，最新日志条目调整为从顶部向下排列展示。
- **长日志截断修复**：修复长日志内容超出屏幕被截断的问题，消息行支持横向滑动查看。
- **弹窗按钮修复**：修复三按钮弹窗中间按钮白底白字看不清的问题，改为 Tonal 按钮样式。
- **版本号读取修复**：修复应用内版本号写死的问题，改为读取实际构建版本号。
- **设置页功能清理**：清理设置页摆设项，其余各项功能真正实现。
- **目录智能识别**：目录选择器预定位到主应用日志目录，选错目录时拒绝并引导用户重选。

### 移除

- **摆设功能移除**：移除设置页未实现的两项摆设功能。

## [0.0.1] - 2026-09-23

### 新功能

- **应用首发**：独立日志查看附属应用首次发布，专门用于读取并展示主应用运行日志。
- **主应用日志读取**：支持读取主应用产生的运行日志文件，供排查问题使用。
- **日志等级筛选**：提供五种日志等级筛选，可分级过滤查看不同优先级输出。
- **关键词搜索高亮**：支持关键词全文搜索匹配，命中内容在日志列表中高亮显示。
- **实时尾随模式**：开启尾随后日志自动滚动至最新条目，实时跟踪应用运行状态。
