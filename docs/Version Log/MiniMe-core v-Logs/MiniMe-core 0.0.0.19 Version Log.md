# MiniMe-core 0.0.0.19 Version Log

> 本次更新新增粒子聚合与玻璃破碎启动动画，内置浏览器反检测能力增强，模型列表支持一键测速，优化上下文窗口判断，修复发版标题规范问题。

**发布日期**：2026-09-25

### 新功能

- **启动动画**：开机新增粒子聚合与玻璃破碎五阶段动画，右上角可跳过，自动适配深浅色主题。

### 改进

- **浏览器隐身增强**：内置浏览器更难被网页识别为自动化环境，操作定位更精准，鼠标移动更贴近真人。
- **模型测速**：添加模型时可一键测试连通性，实时显示网络延迟，便于挑选可用节点。
- **架构细节优化**：应用架构细节优化，提高产品质量，优化用户体验。

### 修复

- **发版标题修复**：修复发版流程中标题硬编码与附属应用标题缺失的问题。
