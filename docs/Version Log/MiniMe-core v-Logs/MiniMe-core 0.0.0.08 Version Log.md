# MiniMe-core 0.0.0.8 Version Log

> 主题设置功能修复与样式打磨版本：修复 v0.0.0.7 主题设置页的 7 项功能缺陷（主题预设颜色不控对话页、背景图无变化、显示偏好无效果、双顶栏、菜单卡片无边距、搜索框常驻、正文首行空行），同步收紧对话流与输入栏间距，搜索交互改为顶栏按钮触发模式。

**发布日期**：2026-09-23

### 改进

- **搜索交互改版**：设置页搜索改为顶栏图标按钮触发，展开输入框实时过滤。
- **对话间距收紧**：消息列表项间距收紧上下边距同步，整体视觉更紧凑。

### 移除

- **常驻搜索框移除**：移除设置页原常驻搜索框，改为顶栏按钮触发模式。

### 修复

- **主题色全局生效**：对话页气泡竖线工具卡片等全部读取主题色，切换实时变色。
- **背景图显示修复**：修复表面遮挡问题，卡片透明度生效背景图重启不丢失。
- **显示偏好生效**：圆角字体动效三项设置全局生效，切换实时响应。
- **双重顶栏修复**：移除自带顶栏复用外层顶栏，与其他设置子页一致。
- **菜单卡片边距修复**：菜单分组卡片增加左右水平边距，不再紧贴屏幕边缘。
- **首行空行修复**：过滤分段器生成的开头空白段，正文从第一行显示。
