# MiniMe-core 0.0.0.13 Version Log

> 主应用模型供应商设置全面升级版本：8维能力标签体系、供应商级连通性测试、采样参数实装、API Path 自定义、请求超时/重试、模型收藏置顶、供应商复制、故障转移，从"基础配置"升级为"专业级模型管理"。

**发布日期**：2026-09-24

### 新功能

- **能力标签扩维**：模型能力标签从3维扩展为8维，不支持能力显示灰色禁用态。
- **模型描述展示**：模型行显示简短能力描述，覆盖主流厂商全系列模型。
- **连通性测试**：编辑添加页均支持一键测试连接，内联显示成功失败原因。
- **采样参数实装**：温度核采样最大输出参数实装，实际传递到所有适配器请求体。
- **API Path自定义**：默认按供应商类型自动填充API路径，支持手动自定义修改。
- **超时重试配置**：请求超时5至120秒，重试0至5次，流式首字节均生效。
- **模型收藏置顶**：星标收藏指定模型，收藏项始终在模型列表顶部显示。
- **供应商复制**：列表项一键复制供应商配置，适合同平台多密钥场景。
- **故障转移**：配置备用供应商后，主供应商失败自动切换备用重试。

### 改进

- **标签颜色主题**：能力标签颜色统一使用主题色，深色模式自动适配。
- **温度范围适配**：温度滑块范围按供应商动态区分，避免超出API合法范围。
- **非对话模型标记**：嵌入语音生图等非对话模型正确标记为不支持工具调用与结构化输出。
- **非流式超时生效**：非流式请求使用配置的超时时间，不再固定120秒。

### 移除

- **硬编码色值移除**：移除能力标签硬编码颜色值，统一改用主题色令牌。

### 修复

- **温度超限修复**：修复Anthropic供应商温度设置超过1.0导致API请求400错误。
- **深色标签修复**：修复代码与结构化输出能力标签在深色模式下颜色不协调。
- **非流式超时修复**：修复非流式请求超时不受用户配置控制的问题，改用配置值。
- **误标问题修复**：修复嵌入语音生图等非对话模型被错误标记为支持工具调用与结构化输出。
- **默认上限修正**：Anthropic最大输出默认值改为保守4096，避免超出模型限制。
