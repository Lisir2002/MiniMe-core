# MiniMe-core 0.0.0.2 Version Log

> 安全加固版本：落地数据库全库加密基础设施（P1 阶段），修复 SQLCipher 空实现与加密失败静默降级两项 P0 安全缺陷。默认仍为明文，用户可在设置页手动开启加密；P2/P3 阶段将逐步推进默认加密与强制加密。

**发布日期**：2026-09-22

### 新功能

- **全库加密支持**：6个物理库可选AES-256加密，设置页一键开启并自动迁移。
- **加密迁移引擎**：明文与加密无损互迁，七步流程加三重校验确保数据完整。
- **迁移崩溃恢复**：启动自动检测迁移中断并安全回滚，覆盖十个崩溃时间点。
- **双层密钥管理**：Keystore主密钥包裹每库独立DEK，密钥不落明文不出Keystore。
- **安全策略文档**：新增SECURITY.md安全策略文档，规范安全披露流程。

### 改进

- **路由驱动工厂**：根据每库加密状态动态选择明文或加密驱动，上层无感知。
- **启动崩溃恢复**：首次数据库访问前执行崩溃恢复，确保迁移中断不损坏。
- **加密设置区块**：安全设置页新增加密状态、开关、进度条与失败重试。
- **加密依赖引入**：引入SQLCipher 4.5.4依赖与ProGuard keep规则。
- **CI静态检测**：新增加密空实现静态检测门禁，阻止占位实现合入。

### 安全

- **加密空实现修复**：修复P0级SQLCipher加密为空实现，改为完整fail-close实现。
- **静默降级修复**：修复P0级加密失败静默降级明文，严格fail-close绝不回退。
- **虚假声明修正**：修正文档中SQLCipher加密读写虚假声明，改为真实状态描述。
