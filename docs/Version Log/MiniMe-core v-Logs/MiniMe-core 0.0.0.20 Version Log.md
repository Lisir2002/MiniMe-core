# MiniMe-core 0.0.0.20 Version Log

本次更新全面升级四大核心模块：启动动画粒子聚合清晰可读并支持风格切换，AI对话新增富文本渲染、对话搜索、消息操作、模板导出等九项增强，终端容器新增文件管理、分屏多会话、快捷命令、资源监控等八项能力，浏览器新增下载管理、密码管理、广告拦截、开发者工具等功能。

### 新功能

- **启动动画**：粒子聚合成MiniMe文字，玻璃破碎3D效果，性能自适应降级，支持风格切换。
- **富文本渲染**：AI回复支持代码高亮、表格、列表、引用，代码块带语言标签和复制按钮。
- **对话搜索**：对话内全文搜索消息，匹配结果高亮，支持上下导航定位，保留搜索历史。
- **消息操作**：长按消息弹出操作面板，支持复制、重生成、编辑、收藏、分享、删除。
- **流式优化**：AI回复智能滚动跟随，上滑显示新消息按钮，打字光标动画，可停止。
- **模型切换**：切换模型时选择保留上下文或清空新对话，显示token估算和窗口占用率。
- **用量可视化**：顶栏显示token用量和窗口占比进度条，使用率超百分之八十变红警告。
- **对话模板**：内置编程、写作、分析、创意四类预设提示词，支持自定义模板和变量。
- **对话导出**：支持Markdown、纯文本、JSON三种格式导出对话，可分享或保存文件。
- **多模型对比**：对比模式最多三个模型同时回答，分屏独立滚动，可评分并采纳回答。
- **文件管理**：容器内文件管理器，支持浏览、编辑、查看、复制剪切、重命名删除、导入导出。
- **终端分屏**：多标签终端会话，支持上下分屏显示，分隔线可拖动，会话状态保留。
- **快捷命令**：常用命令快捷面板，六分类内置命令，支持自定义命令和变量输入。
- **资源监控**：容器CPU、内存、存储、进程实时监控，两秒刷新，点击展开详细指标。
- **终端主题**：内置六套终端配色主题，支持自定义字体大小、行高、光标样式，可预览。
- **密钥管理**：支持生成Ed25519和RSA密钥，加密存储私钥，公钥一键复制。
- **容器快照**：容器快照创建与恢复，最多保留五个自动清理，恢复前自动备份可回滚。
- **标签管理**：浏览器标签长按菜单，支持关闭此标签、关闭其他、全部关闭，网格管理。
- **下载管理**：下载进度实时显示速度和百分比，支持暂停继续取消，通知栏显示。
- **密码管理**：密码加密存储，访问需生物识别，自动填充网页登录表单，强度评分。
- **广告拦截**：内置广告和跟踪器拦截，地址栏盾牌显示拦截数量，可自定义规则。
- **开发者工具**：网页控制台日志、网络请求列表、DOM元素查看，支持执行JavaScript。
- **手势操作**：网页边缘滑动后退前进，页面顶部下拉刷新，双指捏合缩放，三档可调。

### 改进

- **容器重启**：重启容器保留所有数据和配置，重置容器清除根文件系统恢复初始态。
- **切换镜像**：点击切换镜像弹出选择列表，当前镜像高亮标记，运行中切换需确认。
- **镜像源设置**：镜像源支持自定义地址输入，预设多个常用镜像源，保存后立即生效。
- **容器卡片**：容器状态卡片移除粗黑边框，改用柔和阴影，与镜像列表卡片风格统一。

### 修复

- **启动动画**：修复粒子聚合成一团墨迹文字不可读问题，移除旧版灰色胶囊残留。
- **标签栏修复**：修复浏览器标签栏被系统状态栏遮挡，正确处理状态栏和导航栏间距。
- **地址栏修复**：修复地址栏提示文字过长被截断的问题，简化为输入网址或搜索。
- **全局残留**：彻底移除旧版启动动画图标和主题配置，冷启动无图标闪现。
