# MiniMe-core 0.0.0.20 Version Log

> 本次更新全面升级四大核心模块：启动动画粒子聚合清晰可读并支持风格切换，AI对话新增Markdown渲染、对话搜索、消息快捷操作、模板导出等九项增强，终端容器新增文件管理、分屏多会话、快捷命令、资源监控等八项能力，浏览器新增下载管理、密码管理、广告拦截、开发者工具等功能。

**发布日期**：2026-09-25

### 新功能

- **启动动画**：粒子聚合成MiniMe文字清晰可辨，玻璃破碎3D效果，性能自适应降级，支持粒子、简约、经典多种风格切换。
- **Markdown渲染**：AI回复支持代码语法高亮、表格、有序无序列表、引用块，代码块带语言标签和一键复制。
- **对话搜索**：对话内全文搜索消息，匹配结果高亮，支持上下导航平滑定位，保留最近十条搜索历史。
- **消息操作**：长按消息弹出操作面板，AI消息支持复制、重新生成、编辑、收藏、分享、朗读，用户消息支持删除。
- **流式优化**：AI回复智能滚动跟随，上滑后显示新消息按钮，打字光标动画，生成中可随时停止。
- **模型切换**：切换模型时选择保留上下文或清空新对话，显示当前对话token估算和上下文窗口占用率。
- **Token可视化**：顶栏模型名旁显示token用量和窗口占比进度条，使用率超百分之八十变红警告。
- **对话模板**：内置编程、写作、分析、创意四类预设提示词，支持自定义模板和变量替换。
- **对话导出**：支持Markdown、纯文本、JSON三种格式导出对话，可系统分享或保存到文件。
- **多模型对比**：开启对比模式后最多三个模型同时回答，左右分屏独立滚动，可评分并采纳回答。
- **文件管理**：容器内文件管理器，支持浏览、文本编辑、图片查看、复制剪切、重命名删除、导入导出。
- **终端分屏**：多标签终端会话，支持上下分屏显示，分隔线可拖动，切换标签会话状态保留。
- **快捷命令**：常用命令快捷面板，六分类内置命令，支持自定义命令和变量输入，最近使用置顶。
- **资源监控**：容器CPU、内存、存储、进程实时监控，两秒自动刷新，点击展开详细指标和进程排行。
- **终端主题**：内置六套终端配色主题，支持自定义字体大小、行高、光标样式，设置旁实时预览。
- **SSH密钥**：SSH密钥管理，支持生成Ed25519和RSA密钥，加密存储私钥，公钥一键复制。
- **容器快照**：容器快照创建与恢复，最多保留五个自动清理最旧，恢复前自动备份可回滚。
- **标签管理**：浏览器标签长按菜单，支持关闭此标签、关闭其他、全部关闭，多标签网格管理页。
- **下载管理**：下载进度实时显示速度和百分比，支持暂停继续取消，通知栏显示进度，下载历史管理。
- **密码管理**：密码加密存储，访问需生物识别，自动填充网页登录表单，密码强度评分指示。
- **广告拦截**：内置广告和跟踪器拦截，地址栏盾牌显示拦截数量，隐私设置面板可自定义规则。
- **开发者工具**：网页控制台日志、网络请求列表、DOM元素查看、Cookie和本地存储查看，支持执行JavaScript。
- **手势操作**：网页边缘滑动后退前进，页面顶部下拉刷新，双指捏合缩放，手势灵敏度三档可调。

### 改进

- **容器重启**：重启容器保留所有数据和配置，重置容器清除根文件系统恢复初始态，两者行为明确区分。
- **切换镜像**：点击切换镜像弹出镜像选择列表，当前镜像高亮标记，运行中会话切换需二次确认。
- **镜像源**：镜像源支持自定义地址输入，预设阿里云、清华、中科大等镜像源，保存后立即生效。
- **容器卡片**：容器状态卡片移除粗黑边框，改用柔和阴影，与镜像列表卡片视觉风格统一。

### 修复

- **启动动画**：修复粒子聚合成一团墨迹文字不可读问题，移除旧版启动动画灰色胶囊残留，修复背景渐变竖线。
- **标签栏**：修复浏览器标签栏被系统状态栏遮挡的问题，正确处理状态栏和导航栏间距。
- **地址栏**：修复地址栏提示文字过长被截断的问题，简化为输入网址或搜索。
- **全局残留**：彻底移除旧版启动动画图标和主题配置，冷启动无图标闪现。
