# MiniMe-core 0.0.0.12 Version Log

> 日志系统全面升级版本：运行日志页面重构为专业日志查看器，支持等级筛选、文件选择、实时尾随、搜索高亮、横竖屏自适应；同时日志底层深度优化，写入性能大幅提升，新增 FATAL 等级、线程信息、格式版本头、敏感信息脱敏、实时统计等能力，为后续独立日志附属应用奠定基础。

**发布日期**：2026-09-23

### 新功能

- 运行日志页面重构为专业日志查看器：结构化日志行（时间戳+等级徽章+Tag+消息+堆栈折叠），长按复制全文/消息/时间戳/Tag，关键词搜索实时高亮并支持上一处/下一处跳转
- 等级筛选栏常驻显示各等级数量徽章：单击筛选该等级及以上，长按进入多选模式，再次点击折叠该等级所有行
- 文件选择支持快捷范围（今天/近3天/近7天/全部）与自定义日期范围，文件列表显示大小并可多选合并查看
- 实时尾随模式：新日志自动滚动到底部并绿色脉冲高亮，上滑自动暂停并显示「有 N 条新日志」浮动按钮，点击恢复尾随
- 横屏自适应：≥600dp 自动切换左右分栏（左侧列表+右侧详情），竖屏保持堆叠布局
- 日志等级新增 FATAL（致命错误），位于 ERROR 之上，用于标记不可恢复的严重故障
- 日志行新增线程信息 `[thread:name]`，便于排查多线程并发问题
- 日志文件新增格式版本头（`# MiniMe Log Format v1`），记录应用版本与进程 ID，为日志格式演进与兼容性检测提供依据
- 新增实时统计能力：各等级计数、各 Tag 计数，运行时可查询
- 新增耗时记录便捷方法 `timing(tag, label, durationMs)`

### 改进

- 日志写入性能优化：从每条日志单独 open/write/close 改为内存队列缓冲 + 常驻 BufferedWriter，按 64KB 或 500ms 批量 flush，大幅降低 IO 开销
- 文件滚动策略从「超限截断删除全部历史」改为非破坏性滚动（`log-date.txt → .1 → .2`），历史日志完整保留
- 日志导出从全量 readText 入内存改为 8KB 流式复制，避免大文件导出时 OOM
- 日志配置集中管理：日志级别、缓冲大小、文件上限、清理天数等统一由 LogConfig 管理，支持运行时覆盖
- 日志层接口抽象：新增 Logger 接口与 TestLogger 实现，便于单元测试与未来扩展输出目标（网络/数据库）

### 修复

- 修复日志文件超过 5MB 时全部历史被截断删除的问题，改为滚动保留
- 修复多线程并发写入日志时的锁竞争问题，改为单线程写入器串行化处理
- 修复日志导出大文件时可能 OOM 的问题，改为流式复制

### 安全

- 敏感信息统一脱敏：日志写入前自动检测并脱敏 API Key、Access Token、密码、Authorization 头、长 base64 媒体数据等，避免敏感信息泄露到日志文件
- 格式版本头为后续日志格式不兼容变更提供检测机制，附属应用可根据版本号判断是否需要升级
