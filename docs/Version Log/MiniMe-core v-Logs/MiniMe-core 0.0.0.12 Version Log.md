# MiniMe-core 0.0.0.12 Version Log

> 日志系统全面升级版本：运行日志页面重构为专业日志查看器，支持等级筛选、文件选择、实时尾随、搜索高亮、横竖屏自适应；同时日志底层深度优化，写入性能大幅提升，新增 FATAL 等级、线程信息、格式版本头、敏感信息脱敏、实时统计等能力，为后续独立日志附属应用奠定基础。

**发布日期**：2026-09-23

### 新功能

- **日志查看器重构**：结构化日志行支持长按复制，关键词搜索高亮并跳转。
- **等级筛选栏**：等级筛选栏常驻显示各等级数量徽章，单击筛选长按多选折叠。
- **日志文件选择**：支持今天近3天近7天等快捷范围与自定义日期，多选合并查看。
- **实时尾随模式**：新日志自动滚到底部脉冲高亮，上滑暂停显示新日志按钮。
- **横屏自适应**：横屏宽屏自动切换左右分栏布局，竖屏保持堆叠显示。
- **FATAL等级新增**：日志新增FATAL致命错误等级，位于ERROR之上标记严重故障。
- **线程信息记录**：日志行新增线程名标记，便于排查多线程并发写入问题。
- **日志格式版本头**：日志文件新增格式版本头，记录应用版本与进程ID。
- **实时统计能力**：运行时实时统计各等级与各Tag数量，支持随时查询。
- **耗时记录便捷**：新增耗时记录便捷方法，便于测量关键路径执行耗时。

### 改进

- **写入性能优化**：改为内存队列缓冲加批量flush，大幅降低IO开销。
- **日志滚动保留**：文件超限不再截断删除全部历史，按日期滚动完整保留。
- **导出流式复制**：日志导出改为8KB流式复制，避免大文件导出时内存溢出。
- **配置集中管理**：日志级别缓冲大小文件上限统一由配置管理，支持运行时覆盖。
- **日志接口抽象**：新增Logger接口与测试实现，便于单测与扩展输出目标。

### 修复

- **截断问题修复**：修复日志文件超5MB时全部历史被截断删除，改为滚动保留。
- **并发写入修复**：修复多线程并发写入日志锁竞争，改为单线程串行处理。
- **导出OOM修复**：修复日志导出大文件时可能内存溢出，改为流式复制。

### 安全

- **敏感信息脱敏**：日志写入前自动检测脱敏密钥令牌密码及长base64数据。
- **版本兼容检测**：格式版本头为后续不兼容变更提供检测机制，附属应用可据此升级。
