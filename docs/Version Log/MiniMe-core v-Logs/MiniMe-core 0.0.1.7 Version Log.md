# MiniMe-core 0.0.1.7 Version Log

本版本将工具、外部服务与技能合并进同一个能力中心，一处即可查看与管理全部能力；进入任一外部服务还能浏览并取用它的提示词与资源。新版能力页为实验功能，可在开发者选项中开启。

## 新功能

- **能力中心合一**：工具、外部服务与技能合并进同一页面，一处即可查看与管理全部能力。
- **提示词可取用**：进入外部服务可查看它提供的提示词，填好参数即可取出正文内容。
- **资源可直接阅读**：外部服务提供的资源支持按地址打开阅读，文本内容直接呈现。
- **服务形态可辨**：每个服务标注运行方式与启用状态，禁用或连接异常时一目了然。
- **技能对外可用**：技能以标准提示词与资源的形式对外提供，其他工具也能直接取用。
- **实验开关可自选**：本版新增能力以实验开关提供，可在开发者选项中按需开启体验。

## 改进

- **能力清单实时更新**：外部服务连接或断开后，能力清单立即更新，不再停留在旧列表。
- **工具标注更清晰**：工具卡片标注加载方式与审批要求，哪些需要先经你确认一目了然。

## 安全

- **外部内容防注入**：外部服务返回的提示词与资源内容已做安全处理，不会被当作指令执行。

## 已知问题

- **个别服务响应慢**：个别外部服务读取提示词时若长时间无响应会停在加载中，暂不会自动超时。
