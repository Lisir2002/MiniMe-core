# MiniMe-core 0.0.0.3 Version Log

> Agent-First 对话流重构版本：以智能体为中心的任务协作界面，新增工具调用卡片（ToolCallCard）与任务卡片（TaskCard），覆盖 6 种工具状态与 7 种任务状态，配套错误诊断、重试机制与样式清爽化。所有新组件通过 feature flag 双开关控制，默认关闭，现有行为完全不变。

**发布日期**：2026-09-22

### 新功能

- **工具调用卡片**：支持6种状态折叠展开与实时输出提示，长输出可截断复制。
- **任务卡片**：支持7种状态步骤进度与文件产物展示，底部可停止重试。
- **失败重试支持**：失败的工具调用可一键重试，失败任务可从原请求重跑。
- **错误诊断建议**：识别8种常见错误模式，提供修复建议与一键复制命令。
- **灰度双开关**：新旧组件独立开关默认关闭，支持逐步灰度切换。

### 改进

- **对话气泡轻量化**：左对齐限宽去边框改轻投影，增大内边距与圆角。
- **暗色色阶重定义**：统一页面底气泡输入栏色值，文字对比度均达标。
- **同角色消息分组**：连续同角色消息组内紧凑组间宽松，视觉清晰区分。
- **输入栏视觉分离**：输入框圆角淡边框，发送附件等按钮图标统一尺寸。

### 修复

- **运行状态推导修复**：工具执行期间正确显示运行中，不再误判为已完成。
