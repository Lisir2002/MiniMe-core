# MiniMe-core 0.0.0.21 Version Log

> 本次更新全面重构容器文件管理器，新增设置搜索、导出导入、变更历史、开发者选项等六项设置增强，落地启动测量、崩溃捕获、数据库优化等七项性能稳定性提升，修复加密数据库迁移异常。

## 新功能

- **文件管理器**：容器内文件管理全面重构，支持类型识别、网格视图、面包屑导航、长按操作面板、文件属性查看。
- **设置搜索**：设置页支持拼音搜索、模糊匹配、错别字容忍，搜索结果高亮显示，聚焦时推荐常用设置。
- **设置导出**：设置支持按分类选择性导出导入，统一JSON格式，冲突时可选择覆盖或保留，支持加密导出。
- **变更历史**：设置变更自动记录，支持按时间查看历史，单条或批量回滚到之前的配置状态。
- **设置导航**：设置首页重新设计，常用设置置顶，子分组折叠，页面切换带滑入动画，设置项增加描述。
- **即时反馈**：设置变更后即时提示生效状态，需重启的设置显示标记并提供立即重启按钮，危险操作二次确认。
- **开发者选项**：连续点击版本号解锁开发者选项，包含性能监控、日志查看、数据库浏览、网络监控、调试开关。
- **崩溃捕获**：应用异常退出自动捕获崩溃信息，下次启动提示查看报告，开发者选项中可查看崩溃历史。
- **网络监控**：调试模式下记录网络请求历史，显示请求地址、状态码、耗时统计，支持查看请求详情。

## 改进

- **启动动画**：粒子聚合增加发光效果和辉光脉冲，玻璃碎片增加半透明材质、高光边缘、3D立体翻转和光影效果。
- **启动性能**：新增启动耗时测量，非关键组件延迟并行初始化，首屏渲染优化，冷启动更流畅。
- **内存管理**：新增内存监控，定期采样内存使用，高内存占用时自动触发回收，开发者选项可查看内存详情。
- **列表性能**：对话、设置、文件列表优化渲染性能，稳定标识减少重组，长列表滚动更流畅。
- **数据库优化**：新增会话列表排序索引，定期清理过期数据和临时缓存，查询和写入性能提升。
- **电池优化**：新增电池优化开关，低电量时自动降低动画质量和后台轮询，监听系统省电模式。
- **架构细节优化**：应用架构细节优化，提高产品质量，优化用户体验。

## 移除

- **对话搜索**：移除对话内全文搜索功能，包括搜索栏、匹配高亮、上下导航和搜索历史。
- **对话导出**：移除对话导出功能，不再支持Markdown、纯文本、JSON三种格式导出和分享。
- **多模型对比**：移除多模型对比模式，不再支持分屏同时回答、评分和采纳回答功能。

## 修复

- **加密迁移**：修复加密数据库迁移失败导致的初始化异常，明文到加密迁移改用整库导出方案，迁移更稳定。
