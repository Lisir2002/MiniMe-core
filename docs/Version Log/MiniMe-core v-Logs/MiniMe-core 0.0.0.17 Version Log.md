# MiniMe-core 0.0.0.17 Version Log

> 本次更新全面统一 UI 组件体系，将三套并存的组件合并为一套，统一顶栏 Tab 样式为胶囊式分段控件，优化输入框间距、规范指示器交互和供应商卡片布局，提升整体视觉一致性和操作体验。

**发布日期**：2026-09-25

### 改进

- 顶栏 Tab 统一为胶囊式 SegmentedControl 样式，覆盖远程服务器、终端包管理、技能详情、规范查看器、模型管理等9个页面
- 全局 UI 组件体系统一：合并三套并存组件为一套，新增对话框、底部弹窗、输入框、搜索栏、错误状态、状态点、加载指示器等通用组件
- 底部弹窗统一收口：拖拽手柄、手势滑动关闭与色调高度可控，各设置页弹窗交互与样式保持一致
- 聊天输入框与工具栏间距收紧，消除过大空白
- 规范指示器优化：单击展开规范概览浮层，长按切换总开关，显示启用项数量，点击跳转修正为规范流程设置
- 模型供应商卡片布局紧凑化，信息密度提升
- 删除旧版重复组件定义，减少维护成本
