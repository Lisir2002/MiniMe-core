# MiniMe-core 0.0.0.17 Version Log

> 本次更新全面统一 UI 组件体系，将三套并存的组件合并为一套，统一顶栏 Tab 样式为胶囊式分段控件，优化输入框间距、规范指示器交互和供应商卡片布局，提升整体视觉一致性和操作体验。

**发布日期**：2026-09-25

### 改进

- **顶栏Tab统一**：所有页面顶栏Tab统一为胶囊式SegmentedControl，覆盖9个页面。
- **组件体系统一**：合并三套并存组件为一套，新增对话框等10种通用组件。
- **底部弹窗收口**：统一拖拽手柄与手势关闭，各页面弹窗交互样式一致。
- **输入间距收紧**：聊天输入框与工具栏间距收紧，消除过大空白。
- **规范指示器优化**：单击展开概览浮层，长按切换总开关，跳转修正为规范设置。
- **供应商卡片紧凑**：模型供应商卡片布局紧凑化，信息密度显著提升。

### 移除

- **旧版组件移除**：删除CyberComponents与AppComponents，统一为单一组件体系。
