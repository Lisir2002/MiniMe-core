# MiniMe-core 0.0.0.5 Version Log

> 混合模式 v2 样式迭代版本：去掉对话流外层多余气泡容器（TaskAccordion 白色卡片/外层头部/子容器标签头全部去除），消息直接在页面背景上展示；消息尾部新增时间戳显示；输入栏优化（">" 符号与光标同行、边距收紧、模式按钮恢复文字标签）。

**发布日期**：2026-09-22

### 改进

- 去掉对话流外层气泡：TaskAccordion 白色大卡片改透明（去边框/阴影），去掉外层头部（图标/标题/N条/时间/展开箭头）和"用户消息"/"回复"标签头（图标/文字/序号/箭头），消息直接在页面背景上展示，组间距 16dp，展开/折叠逻辑保留且默认展开。
- 消息尾部新增时间戳显示（HH:mm 格式，10sp 弱化色，右对齐，复用已有 `timestamp` 字段），快捷按钮常驻轻量化（图标间距收紧至 4dp）。
- 输入栏优化：左侧 ">" 符号与输入框改同一行（Row 垂直居中），上下边距收紧至 10dp，模式按钮从圆形图标恢复为胶囊形文字标签（BUILD/PLAN/AUTO，复用项目 ChatAccent 三色语义色，点击切换逻辑保留）。
