# MiniMe-core 0.0.0.14 Version Log

> 模型管理体验全面优化版本：供应商编辑页10项深度优化、防截图录屏用户可配置、API Path开关模式、模型服务商与默认模型合体为统一模型管理页面。

**发布日期**：2026-09-24

### 新功能

- **防录屏可配置**：安全设置页可自主开关防截图录屏，默认开启，关闭后允许截图。
- **模型管理合体**：原服务商与默认模型合并为统一模型管理页面，顶栏Tab切换。
- **Key一键粘贴**：供应商编辑页API Key新增一键粘贴按钮，带眼睛显隐切换。
- **空状态引导**：无模型时居中显示图标，提供从服务商拉取与手动输入双按钮。
- **错误语义化**：测试连接错误按状态码分别提示Key无效、路径错误或网络不可达。

### 改进

- **Path开关模式**：默认自动补充路径，开启后手动填写并非空校验。
- **测试按钮移位**：测试连接按钮从Key下方移至Base URL输入框正下方。
- **编辑页分组**：供应商编辑页按基本信息连接配置高级参数轻量分组，带分隔线。
- **类型切换联动**：切换供应商类型时若已自定义路径，自动填充新类型默认路径。
- **完整URL模式联动**：Full URL模式开启时API Path开关自动禁用，并提示由Base URL决定。
- **高级区块折叠**：Response开关与兼容端点策略区块移入高级参数折叠区，连接区更简洁。

### 移除

- **顶栏按钮移除**：供应商编辑页顶栏移除添加模型按钮，模型Tab已有入口。

### 修复

- **新建收藏修复**：新建供应商时点收藏不再静默失败，保存后同步数据库。
- **Path联动修复**：修复切换供应商类型后自定义API Path不联动，导致请求404。
