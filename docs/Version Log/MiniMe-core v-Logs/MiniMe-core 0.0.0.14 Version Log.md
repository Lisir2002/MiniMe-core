# MiniMe-core 0.0.0.14 Version Log

> 模型管理体验全面优化版本：供应商编辑页10项深度优化、防截图录屏用户可配置、API Path开关模式、模型服务商与默认模型合体为统一模型管理页面。

**发布日期**：2026-09-24

### 新功能

- 防截图录屏用户可配置开关：安全设置页可自主开关，默认开启，关闭后供应商编辑页允许截图录屏
- 模型管理页面合体：原「模型服务商」与「默认模型」合并为统一「模型管理」页面，顶栏 Tab 切换服务商/默认模型，设置菜单减少一个入口
- 供应商编辑页 API Key 一键粘贴按钮（眼睛显隐 + 粘贴双图标）
- 供应商编辑页模型空状态引导：无模型时居中显示图标 + 「从服务商拉取」/「手动输入」双按钮
- 测试连接错误语义化：401→API Key无效或已过期，404→Base URL或API Path错误，超时→网络不可达

### 改进

- API Path 改为开关模式：默认关闭自动补充默认路径（OpenAI=/v1/chat/completions，Anthropic=/v1/messages，Gemini=/v1beta），打开后手动填写且非空校验
- 测试连接按钮从 API Key 下方移至 Base URL 输入框正下方
- 供应商编辑页轻量分组：基本信息 / 连接配置 / 高级参数三组，Section 标题 + 分隔线，不再14个元素平铺
- 供应商类型切换时，若已开启自定义 API Path，自动填充新类型默认路径（静默处理，不弹提示）
- Full URL 模式开启时 API Path 开关自动禁用，并提示「Full URL 模式下 Path 由 Base URL 决定」
- Response API 开关和兼容端点策略区块（兼容策略/自动降级/ViewImageGuard）移入高级参数折叠区，连接配置区更简洁
- 供应商编辑页顶栏移除添加模型按钮（模型 Tab 内已有拉取和手动输入入口）

### 修复

- 新建供应商时点收藏模型静默失败：新建模式仅更新本地收藏状态，保存后同步到数据库，不再调用不存在的记录
- 切换供应商类型后自定义 API Path 不联动，导致请求 404
