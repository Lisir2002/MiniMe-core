# MiniMe-core 0.0.0.22 Version Log

本次更新新增独立版本更新中心，支持最新版本与历史版本双 Tab 浏览和下载；紧急修复数据库加密迁移失败与凭据解密崩溃两个关键问题；重构备份还原页面提升恢复安全性；修复开发者选项无法解锁的问题；同时移除设置导出导入与变更历史功能。

## 新功能

- **版本更新**：新增独立版本更新中心，双 Tab 浏览最新版本与历史版本，支持完整更新日志、页面内下载进度和旧版回退安装。
- **启动检查**：应用启动时静默检查新版本，有更新时在入口显示红点提示，不弹窗打扰，可在设置中关闭。

## 修复

- **加密迁移**：修复 sqlcipher_export 结果行未消费导致的 another row available 错误，逻辑版本升级至 v3 自动重置历史失败状态。
- **凭据解密**：修复 V2 解密失败时抛出异常导致应用崩溃的问题，改为降级返回空串并记录密文长度与密钥状态日志。
- **开发者选项**：修复连续点击版本号无法解锁开发者选项的问题，新增点击次数提示和解锁状态持久化，解锁后显示入口。

## 移除

- **设置导出**：移除设置导出导入功能，不再支持按分类导出、加密备份和冲突合并操作。
- **变更历史**：移除设置变更历史与回滚功能，不再自动记录配置变更和单条批量回滚。

## 改进

- **备份还原**：备份与还原页全面重构为四区卡片布局，恢复流程增加安全点校验和完整性验证机制。
