# MiniMe-core 0.0.0.23 Version Log

本次更新全面重构安全设置页面，新增安全评分概览、6库加密状态明细、凭据轮换历史、敏感操作审计日志等功能；将零幻觉容忍设置独立为单独页面；重做启动动画为粒子聚合与玻璃破碎效果；紧急修复历史版本页面闪退和数据库加密迁移临时文件残留问题。

## 新功能

- **安全评分概览**：新增安全评分卡片，综合加密状态、生物识别、防截图等给出0-100分和风险项跳转。
- **加密状态明细**：数据库加密卡片显示6个库各自的加密状态、文件大小和迁移进度，支持手动校验。
- **轮换历史记录**：凭据密钥轮换显示最近5次轮换时间和版本号，超90天未轮换自动提醒。
- **审计日志**：新增敏感操作审计日志，记录加密开关、密钥轮换、紧急解锁等操作，可清空。
- **ZTH独立页**：零幻觉容忍设置从安全页移出，独立为单独设置页面，主菜单新增入口。

## 改进

- **生物识别配置**：生物识别保护支持自定义保护范围和验证超时时间，设备不支持时自动禁用。
- **防截图配置**：防截图录屏支持选择保护范围，新增一键测试防截图是否生效。
- **紧急解锁增强**：紧急解锁显示历史记录，连续5次失败锁定5分钟，确认提示更醒目。
- **启动动画重做**：启动动画重做粒子聚合多层发光效果和玻璃破碎材质，跟随主题色。
- **UI统一**：安全设置页面全部卡片、按钮、弹窗统一为项目组件，错误和成功提示规范化。

## 修复

- **历史版本闪退**：修复历史版本页面点击展开时嵌套垂直滚动导致的应用闪退。
- **迁移临时文件**：修复数据库加密迁移失败后临时文件残留导致无法重新迁移的问题，逻辑版本升至v4。
- **生物识别文案**：修复生物识别保护说明文字错误拼接凭据轮换说明的问题。
- **紧急解锁重复**：修复紧急解锁主密钥说明文字重复显示两遍的问题。
- **轮换按钮卡住**：修复凭据密钥轮换按钮在异常情况下永久卡在轮换中的问题。
