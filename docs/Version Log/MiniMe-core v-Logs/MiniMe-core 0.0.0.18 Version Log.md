# MiniMe-core 0.0.0.18 Version Log

> 本次更新修复多项数据持久化问题，新增SFTP挂载冷启动自动重连，优化容器初始化状态判断，提升应用稳定性与使用体验。

**发布日期**：2026-09-25

### 改进

- **SFTP自动重连**：远程SFTP挂载支持冷启动自动重连，开机后无需手动重新连接。
- **持久化加固**：多项设置项持久化机制加固，降低重启后配置丢失风险。
- **架构细节优化**：应用架构细节优化，提高产品质量，优化用户体验。

### 修复

- **容器状态修复**：修复冷启动后本地终端容器初始化状态误判为未初始化的问题。
- **外观设置修复**：修复外观设置重启应用后被清空的问题，设置项正确持久化保存。
- **搜索历史修复**：修复设置搜索历史重启后丢失的问题，历史记录正确持久化。
- **配置导出修复**：修复规范流程配置导出时布尔值与整数值读取错误的问题。
