# MiniMe-core 0.0.1.8 Version Log

本版本强化了网络连接的稳定性与启动阶段的观感，服务地址异常时会自动切换可用线路，不再长时间干等；同时大幅度简化了模型切换与工具入口的路径，操作更集中顺手。

## 新功能

- **网络自动换线**：某个服务地址响应异常时自动切换可用线路，不再干等直至超时。
- **外部服务分层**：外部服务支持按层级逐层查看与管理，助手也拥有独立的设置页面。
- **侧边栏可滑动**：从屏幕右缘向内滑动即可呼出工具抽屉，向左拖动面板即可关闭。

## 改进

- **切换模型更顺**：更换模型不再逐次确认是否保留记录，直接延续当前对话继续。
- **工具入口统一**：设置与打包器入口统一收进右侧工具抽屉，左侧只保留历史会话。
- **两侧不再重叠**：展开某一侧边栏时另一侧自动收起，避免两个面板同时占据屏幕。
- **启动进度真实**：开机进度与实际加载状态同步，加载完成即刻进入，不再空转。
- **开屏不再闪白**：启动时先显示系统开屏画面，到首帧自然衔接，不再中途闪白。
- **开机动画流畅**：降低了开机动画的绘制开销，中低端设备上也能保持稳定的帧率。
- **菜单更好理解**：设置菜单改用通俗说法替换技术术语，一眼即可看出各自用途。
- **列表错峰显现**：工具抽屉打开时菜单依次错峰显现，按压条目有轻微下沉反馈。

## 移除

- **左侧入口收拢**：左侧边栏底部的设置与打包器入口已移除，统一改由右侧抽屉进入。

## 修复

- **删除会话不再崩**：消息或检查点较多的会话删除时会直接崩溃，现已完整清理关联数据。
- **日志实时刷新**：日志查看器打开后持续自动更新，不再停留在旧内容漏掉最新日志。
- **压缩不再假失败**：超长对话压缩失败曾被当成网络问题，现已修正并自动限制单次规模。
- **回复不再重吐**：网络重试会让已输出的内容重复出现，现已重写重试判断避免重复。
- **假网络波动消失**：长时间空闲的连接被静默丢弃会误报网络波动，现已加入保活探测。

## 已知问题

- **个别服务响应慢**：个别外部服务读取提示词时若长时间无响应会停在加载中，暂不会自动超时。
