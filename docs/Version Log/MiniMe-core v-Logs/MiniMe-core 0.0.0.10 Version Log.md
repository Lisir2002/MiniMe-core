# MiniMe-core 0.0.0.10 Version Log

> 对话流与设置体验深度打磨版本：基于真机验收逐项修复 23 项问题。新增会话列表左滑快捷操作、长文本半屏↔全屏展开编辑面板、模型输出弹性跟随滚动与回到底部按钮；思考过程改为「流式实时展开、结束自动折叠」；主题设置页自身全面接入令牌（圆角/配色预览/动效预览），AI 文件改动实时同步侧边栏。

**发布日期**：2026-09-23

### 新功能

- **会话左滑操作**：左滑露出重命名与删除按钮，删除可撤销，同一时刻仅一行展开。
- **长文本展开编辑**：输入超长时可半屏或全屏展开编辑，与主输入框实时双向同步。
- **输出跟随滚动**：底部时新内容自动平滑跟随，上滑暂停，右下角回到底部按钮。
- **动效实时预览**：动效强度滑块旁提供实时动画预览，拖动滑块直观感受快慢。

### 改进

- **思考流式折叠**：思考期间实时展开跟随，结束后自动折叠，手动操作优先。
- **主题卡片预览**：未选中卡片显示迷你配色预览，使用中标签移至右上角。
- **预览贴近真实**：预览补全附件按钮、占位文字与发送按钮，切换更直观。
- **输入间距收紧**：文本区上下内边距收紧，整体更紧凑，可点击区域保持不变。

### 修复

- **设置页圆角跟随**：设置页内卡片按钮全部接入动态圆角，切换风格实时变化。
- **文件树实时同步**：AI对话中创建修改删除文件后，侧边栏文件树立即刷新。
- **代码块边界清晰**：思考中代码块背景加深并加强边框，与背景区分边界清晰可辨。
- **尾部空白统一**：渲染前清理首尾空段落合并连续空行，消息尾部间距统一。
- **思考动画衔接**：流式思考期间末尾保持跳动指示，阶段间平滑交接无空档。
- **草稿按会话隔离**：草稿按会话隔离，切换或新建会话时自动清空，不再串对话。
- **动效档位生效**：补全遗漏动画消费点，页面切换卡片展开弹窗均跟随强度。
