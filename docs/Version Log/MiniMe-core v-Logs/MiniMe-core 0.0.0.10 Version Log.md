# MiniMe-core 0.0.0.10 Version Log

> 对话流与设置体验深度打磨版本：基于真机验收逐项修复 23 项问题。新增会话列表左滑快捷操作、长文本半屏↔全屏展开编辑面板、模型输出弹性跟随滚动与回到底部按钮；思考过程改为「流式实时展开、结束自动折叠」；主题设置页自身全面接入令牌（圆角/配色预览/动效预览），AI 文件改动实时同步侧边栏。

**发布日期**：2026-09-23

### 新功能

- 会话列表支持左滑露出快捷操作：基于 AnchoredDraggable，左滑后右侧出现「重命名」（蓝）与「删除」（红）两个按钮；删除直接执行并弹出 Snackbar 可撤销，重命名复用现有弹窗；同一时刻仅一行展开，长按完整菜单保留
- 长文本展开编辑面板：输入内容超出单行时右侧出现展开按钮，点击打开双锚点底部面板，支持半屏与全屏两档、顶部拖拽手柄按住切换，面板内多行编辑并与主输入框实时双向同步，底部发送
- 模型输出弹性跟随滚动：位于底部时新内容自动平滑跟随，主动上滑查看历史时暂停跟随不被拉回，滑回底部恢复跟随；不在底部时右下角显示「回到底部」浮动按钮
- 主题设置新增动效预览：动效强度滑块旁提供实时预览动画，拖动滑块可直观感受快慢，0% 即时跳变、100% 最慢

### 改进

- 思考过程流式交互优化：思考持续输出期间默认保持展开并实时跟随，一段思考结束后自动折叠；用户手动展开或折叠的操作始终优先
- 主题预设卡片体验优化：未选中卡片上半部分显示该主题的迷你配色预览（背景/卡片/气泡），「使用中」标签从底部移至右上角角标，所有卡片高度保持一致
- 主题设置页实时预览增强：预览中的输入框补全附件按钮、占位文字与圆形发送按钮，更接近真实对话界面，切换主题/圆角/字号时变化更直观
- 输入框与工具栏间距收紧：文本区上下内边距由 10dp 收紧至 6dp，整体更紧凑（可点击区域保持不变）

### 修复

- 修复主题设置页自身圆角不跟随（灯下黑）：设置页内卡片、选择器、按钮等全部接入动态圆角令牌，切换圆角/直角/胶囊风格时页面自身实时变化（滑块手柄与三个示意图形保持固定）
- 修复 AI 文件改动不实时同步：AI 在对话中创建、修改、删除文件后，侧边栏工作台文件树立即刷新对应目录，无需退出再进入
- 修复思考中代码块与背景融为一体：代码块背景加深并加强边框，边界清晰可辨
- 修复回复尾部出现大小不一的空白：渲染前清理首尾空段落、合并连续空行，不同消息尾部间距统一
- 修复思考动画在回复未完成时提前消失：流式思考期间在内容末尾保持跳动指示，思考、正文阶段动画平滑交接，不再出现无动画空档或双重打点
- 修复新建对话时上一个对话的输入草稿被带入：草稿按会话隔离，切换或新建会话时清空，不再串对话
- 修复动效强度档位切换无真实效果：补全遗漏的动画消费点，页面切换、卡片展开、弹窗等动效现在跟随强度设置
