# MiniMe-core 0.0.0.11 Version Log

> 工作台与对话绑定修复 + AI 回复消息持久化加固版本：修复删除工作台不级联删除对话、备份恢复丢失绑定关系等严重 Bug；同时为 AI 回复增加三层持久化防护，彻底解决应用被杀导致回复消息丢失的问题。

**发布日期**：2026-09-23

### 修复

- **工作台级联删除**：删除工作台时同步删除绑定对话及全部消息，提示不可恢复。
- **备份保留绑定**：备份恢复时保留会话原工作台绑定，仅空路径才兜底。
- **绑定列表接线**：工作台详情页绑定对话列表正确显示，可查看每个工作台对话。
- **切换选最近会话**：切换工作台自动选中最近会话，增加竞态保护防旧结果覆盖。
- **回复定期落库**：流式回复每2000字或3秒写库，应用被杀最多丢几秒。
- **写入不可取消**：消息持久化使用不可取消上下文，协程取消不中断写入。
- **异常兜底保存**：流式异常中断时兜底保存已收内容，正常完成不重复落库。

### 安全

- **三层持久化防护**：定期落库加不可取消写入加异常兜底，杜绝回复丢失。
