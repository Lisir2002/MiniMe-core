# MiniMe-core 0.0.0.11 Version Log

> 工作台与对话绑定修复 + AI 回复消息持久化加固版本：修复删除工作台不级联删除对话、备份恢复丢失绑定关系等严重 Bug；同时为 AI 回复增加三层持久化防护，彻底解决应用被杀导致回复消息丢失的问题。

**发布日期**：2026-09-23

### 修复

- 删除工作台时级联删除绑定的对话及全部消息：删除确认框显示将同时删除的对话数量，提示"不可恢复"，避免产生数据库中存在但任何工作台都不可见的幽灵会话
- 备份恢复时保留会话原始工作台绑定关系：仅当原始路径为空时才兜底到当前工作台，不再强制全部覆盖
- 工作台详情页"绑定对话"列表正确显示：回调已接线，可查看每个工作台绑定的对话
- 切换工作台时自动选择该工作台下的最近会话，增加竞态保护：快速切换时旧查询结果不会覆盖新会话 ID
- AI 回复流式期间定期持久化：每累积 2000 字符或间隔 3 秒写入一次数据库，应用被杀时最多丢失最后几秒内容而非整条回复
- 消息持久化写入使用不可取消上下文：协程取消时已启动的数据库写入不会中断，所有持久化调用点自动受益
- 流式异常中断时兜底保存已收到的内容：处理流式刚开始就异常终止的极端情况，正常完成时不重复落库

### 安全

- 三层持久化防护相互搭配：定期落库（主力）+ 不可取消写入（保障）+ 异常兜底（最后防线），彻底解决 AI 回复因应用被杀或协程取消而丢失的问题
