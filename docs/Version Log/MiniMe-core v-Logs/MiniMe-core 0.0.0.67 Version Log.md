# MiniMe-core 0.0.0.67 Version Log

v0.0.0.54 至 v0.0.0.66 合并归档。底栏全套功能整体移除并待重新设计导航，顶栏统一为毛玻璃风格，新增浏览器指纹管理与AI反爬，优化主题设置页，加固数据库启动崩溃防护。

## 新功能

- **指纹管理**：设置新增浏览器与指纹入口，支持查看、切换、创建、删除与校验，内置6种地区模板。
- **智能反爬**：反爬策略引擎升级为AI驱动，自动识别10种反爬模式并选择最优应对策略。
- **无感恢复**：数据丢失告警改为后台无感自动恢复，不再弹出全局提示窗，避免打扰用户。

## 改进

- **毛玻璃顶栏**：顶栏背景改为半透明毛玻璃，返回与操作按钮分组玻璃容器包裹。
- **搜索展开**：顶栏支持搜索模式，点击搜索图标标题平滑过渡为搜索输入框。
- **菜单统一样式**：全项目21处下拉菜单统一为圆角卡片加阴影样式，视觉一致。
- **预览置顶**：实时预览卡片滚动时自动置顶，置顶期间微折叠节省屏幕空间。
- **调色选色**：颜色自定义采用色相调色盘加预设色板组合，选色更直观高效。
- **动效演示**：返回主题设置页时动效演示自动播放一次，无需手动触发。
- **布局重排**：预览、外观模式、主题预设、显示偏好、颜色自定义按使用频率重排。
- **检出确认**：切换分支前弹出确认对话框，提示未保存变更，避免切换后丢失工作进度。
- **容器引导**：容器未启动时Git页面显示引导卡片，提示用户先启动容器。
- **状态增强**：Git状态页增强暂存与取消暂存、差异查看、操作反馈，分支页支持删除确认。
- **操作健壮**：浏览器操作新增页面健康状态追踪，错误返回自动附带智能恢复建议。
- **策略丰富**：反爬应对策略从4种扩充至7种，新增切换指纹加降频、人类化行为策略。

## 移除

- **底栏整体移除**：底部导航栏及相关交互全部移除，后续重新设计导航方案。
- **Git功能回退**：暂存区管理、危险操作确认等Git深度优化临时回退，排除启动崩溃风险。

## 修复

- **双重顶栏**：模型管理页移除独立顶栏，由设置页统一顶栏提供返回与标题。
- **状态栏叠加**：主页面禁用系统间距自动消费，状态栏间距统一由各页顶栏内部处理。
- **顶栏统一**：浏览器顶栏改用统一容器加状态栏间距包裹，与聊天页参数一致。
- **菜单定位**：操作审计页三点菜单弹出位置从左上角修正为按钮正下方。
- **启动崩溃回退**：回退数据库异步化与启动动画相关代码，修复无日志闪退问题。

## 安全

- **密码保留**：数据库密码在首次打开后保留在内存中，避免重复输入。
- **损坏恢复**：数据库打开失败时自动备份损坏文件并重建空库，历史数据可事后恢复。
