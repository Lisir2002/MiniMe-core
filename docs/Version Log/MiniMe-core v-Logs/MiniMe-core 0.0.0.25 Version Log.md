# MiniMe-core 0.0.0.25 Version Log

本次更新全面重设计弹窗与底部抽屉为统一组件，开发者选项重构为性能/调试/监控/数据四Tab并新增FPS内存曲线与ANR监控；关于页新增QQ反馈群与中英文说明文档；修复多页面双顶栏与顶栏混用问题；远程工作区与终端设置深度优化，文件浏览器视觉统一。

## 新功能

- **开发者选项重构**：开发者选项改为性能/调试/监控/数据四Tab，新增FPS内存实时曲线、ANR监控、KV存储浏览。
- **弹窗统一组件**：新增确认/输入/加载/结果四类通用弹窗和底部抽屉统一组件，迁移原有自定义弹窗。
- **关于页QQ反馈**：关于页新增QQ反馈群和开发者QQ入口，支持扫码或直接打开QQ添加好友。
- **说明文档**：关于页新增项目说明文档，支持中英文切换查看。
- **远程同步设置**：远程工作区新增同步方向、冲突策略、自动同步间隔等持久化设置。
- **终端新设置**：终端设置新增光标样式、光标闪烁、滚动缓冲行数、退出确认等选项。

## 修复

- **双顶栏修复**：修复GuardLogs/RuleManager/NormFlowDiagnosis等状态子页双顶栏问题，改为独立全屏。
- **顶栏统一**：全局统一使用AppTopAppBar，消除原生TopAppBar混用，涉及10个文件。
- **Native查看器**：修复代码查看器双顶栏，错误展示改为友好提示加重试按钮。
- **JNI函数名**：修复native代码查看器JNI函数名下划线转义错误导致的符号查找失败。
- **无效开关清理**：删除强制深色、慢速网络、布局边界等5个无效调试开关。

## 改进

- **远程工作区优化**：连接卡增加协议标签和测试连接，挂载卡显示路径和状态圆点，FTP密码支持显隐和URL复制。
- **终端设置优化**：字号改为滑块调节，配色增加预览色块，新增AMOLED黑配色，支持恢复默认。
- **文件浏览器统一**：提取通用文件项和图标组件，统一代码浏览器与容器文件管理器的视觉样式。
- **网络监控增强**：网络监控增加统计卡片和状态码颜色标识，详情改用底部抽屉展示。
- **崩溃历史详情**：崩溃详情改用代码查看器风格展示，支持横向滚动查看长堆栈。

## 文档

- **UI设计规范**：新增docs/ui-standards.md设计规范文档，统一组件与视觉约定。
