# MiniMe-core 0.0.0.8 Version Log

> 主题设置功能修复与样式打磨版本：修复 v0.0.0.7 主题设置页的 7 项功能缺陷（主题预设颜色不控对话页、背景图无变化、显示偏好无效果、双顶栏、菜单卡片无边距、搜索框常驻、正文首行空行），同步收紧对话流与输入栏间距，搜索交互改为顶栏按钮触发模式。

**发布日期**：2026-09-23

### 改进

- 设置页搜索交互改为顶栏按钮触发模式：主菜单顶栏右侧显示搜索图标，点击后顶栏展开为搜索输入框（带关闭按钮 + 自动聚焦 + 实时过滤），移除原常驻搜索框，参考 Android 原生设置交互
- 对话流与输入栏间距收紧：消息列表 item 间距从 8dp 收紧至 4dp，上下边距同步收紧，整体视觉更紧凑

### 修复

- 主题预设颜色现在正确控制对话页面：用户气泡、AI 回复竖线、工具卡片、品牌渐变、Markdown 代码块/链接/引用/表格等全部从硬编码改为读取主题色，切换预设（Default/Cyber/Sunset/Forest/Ocean/Mono）后对话页实时变色；同时补全 Material ColorScheme 映射遗漏字段（outlineVariant/tertiary/errorContainer/secondaryContainer 等）
- 背景图选择后正确显示且重启不丢失：修复根 Surface 不透明遮挡背景图的问题，卡片透明度设置生效，Photo Picker URI 持久化授权确保冷启动后背景图不丢失
- 显示偏好（圆角风格/字体大小/动效强度）现在生效：圆角风格切换后用户气泡和工具块圆角实时变化（圆角/直角/胶囊），字体大小缩放全局文字，动效强度控制脉冲动画速度
- 修复主题设置页双重顶栏：移除 ThemeSettingsScreen 自带的 Scaffold + AppTopAppBar，复用 SettingsScreen 外层顶栏，与其他设置子页保持一致
- 修复设置菜单卡片左右紧贴屏幕边缘：菜单分组卡片增加 16dp 水平边距
- 修复 AI 回复正文首行永远空行：过滤 Markdown 分段器生成的开头空白段，正文从第一行开始显示
