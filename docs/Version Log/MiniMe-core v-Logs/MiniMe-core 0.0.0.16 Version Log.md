# MiniMe-core 0.0.0.16 Version Log

> 本次更新重构规范流程系统，引入仪表盘、预设方案、细粒度注入控制与安全护栏，让AI行为更可控；合并工具服务与开放服务为统一MCP中心，优化模型卡片展示。

**发布日期**：2026-09-25

### 新功能

- 规范流程仪表盘：顶部实时显示运行状态、注入量与拦截次数，点击查看注入诊断详情
- 预设方案：严格、标准、极简三种预设一键应用，卡片展示各项配置差异
- 细粒度注入控制：step前注入拆分为目标、静态规则、SOP等5个独立开关
- 安全护栏：新增危险命令拦截、大文件保护、路径越界检测三项护栏
- 内置规范查看器：可查看12篇静态规则和6篇SOP的完整内容
- 注入诊断面板：实时查看每轮注入内容、各源字符数与裁剪情况
- 护栏拦截日志：记录最近50条拦截记录，可按时间查看详情
- 分层规则管理：可单独启用或禁用每一条内置规则
- 配置导入导出：规范流程配置可导出为JSON备份或分享
- 聊天规范指示器：输入框上方显示规范运行状态，点击跳转设置
- MCP中心：工具服务与开放服务合并为统一页面，Tab切换，总览状态一目了然
- 推理预算强度：低、中、高三档思考强度可选
- 空转收敛阈值：3、6、10轮无产出自动结束回合

### 改进

- 规范流程页面重构为仪表盘布局，分组按蓝、红、绿主题色区分，支持折叠
- 模型卡片能力标签改为单行横向滚动，功能按钮独立成行
- 上下文输入输出标签从图标改为文字显示
- MCP服务器token掩码显示，重生成需二次确认
- MCP连接失败可展开查看详情，支持自动重试
- 规范流程开关行显示当前配置摘要，如强度中、阈值6轮

### 修复

- 修复SOP摘要开关开启后不生效的问题
- 修复规范流程总开关关闭后部分注入仍生效的问题
