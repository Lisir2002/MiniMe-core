# MiniMe-core 0.0.0.16 Version Log

> 本次更新重构规范流程系统，引入仪表盘、预设方案、细粒度注入控制与安全护栏，让AI行为更可控；合并工具服务与开放服务为统一MCP中心，优化模型卡片展示。

**发布日期**：2026-09-25

### 新功能

- **规范仪表盘**：顶部实时显示运行状态、注入量与拦截次数，可看诊断详情。
- **预设方案**：严格标准极简三种预设一键应用，卡片展示配置差异。
- **细粒度注入控制**：step前注入拆分为目标静态规则SOP等5个独立开关。
- **安全护栏**：新增危险命令拦截、大文件保护、路径越界检测三项护栏。
- **规范查看器**：内置规范查看器，可查看12篇静态规则与6篇SOP完整内容。
- **注入诊断面板**：注入诊断面板实时查看每轮注入内容、各源字符数与裁剪详情。
- **护栏拦截日志**：护栏拦截日志记录最近50条拦截记录，可按时间查看详情。
- **分层规则管理**：分层规则管理，可单独启用或禁用每一条内置规范规则。
- **配置导入导出**：规范流程配置支持导入导出，可导出为JSON备份或分享。
- **聊天规范指示器**：输入框上方显示规范运行状态指示器，点击跳转规范设置。
- **MCP中心**：工具服务与开放服务合并为统一页面，Tab切换总览状态。
- **推理预算强度**：推理预算强度设低中高三档，可按需选择思考强度。
- **空转收敛阈值**：空转收敛阈值设3、6、10轮，无产出自动结束回合。

### 改进

- **规范页面布局**：重构为仪表盘布局，分组按蓝红绿主题色区分支持折叠。
- **模型卡片标签**：模型卡片能力标签改为单行横向滚动，功能按钮独立成行。
- **上下文标签文字**：上下文输入输出标签从纯图标改为文字显示，更易辨认。
- **Token掩码显示**：MCP服务器访问token掩码显示，重生成需二次确认防误操作。
- **MCP失败详情**：MCP连接失败可展开查看详细错误信息，支持自动重试。
- **开关行摘要**：规范流程开关行显示当前配置摘要，如强度中阈值6轮。

### 修复

- **SOP开关修复**：修复SOP摘要开关开启后不生效的问题，恢复正常功能。
- **总开关修复**：修复规范流程总开关关闭后部分注入仍生效的问题，彻底关闭。
