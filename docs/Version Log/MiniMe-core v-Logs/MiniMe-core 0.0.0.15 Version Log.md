# MiniMe-core 0.0.0.15 Version Log

> 本次更新让每个模型都能独立调节采样参数（温度/核采样/最大输出），与供应商默认值互不干扰；同时全面升级默认模型选择体验，智能排序让你更快找到合适的模型。

**发布日期**：2026-09-25

### 新功能

- 模型级采样参数独立调节：每个模型可单独设置温度、核采样、最大输出，不再受供应商统一参数限制
- 采样参数继承/覆盖状态透明显示：未覆盖时标注「继承供应商默认」，已覆盖时高亮显示
- 一键「恢复默认」：清除模型级覆盖，回归供应商默认值
- Max Tokens 覆盖值自动校验：不超过模型输出上限
- 默认模型智能排序：选择识图模型时，支持识图的自动排前面，不兼容的醒目提示「可能不支持识图」
- 压缩模型按上下文大小降序排列，大上下文优先
- 默认模型列表右侧展示能力标签预览，一目了然
- 搜索同时匹配模型名称和供应商名称
- 模型选择弹窗增加关闭按钮，空状态增加引导提示

### 改进

- 默认模型页面统一使用图标化能力标签（输入→输出图标 + 点击文字说明 + 上下文双尺度）
- 模型行信息更丰富：模型名 + 供应商名·描述 + 能力标签
- 供应商编辑页高级参数标注「默认值，模型可单独覆盖」
- 压缩模型图标更换，语义更清晰
- 「跟随对话」选项增加图标标识

### 修复

- 删除供应商时自动清理所有关联模型的采样参数配置，避免残留数据
- 模型级采样参数修改不影响供应商级默认配置，两者严格隔离
