# MiniMe-core 0.0.0.15 Version Log

> 本次更新让每个模型都能独立调节采样参数（温度/核采样/最大输出），与供应商默认值互不干扰；同时全面升级默认模型选择体验，智能排序让你更快找到合适的模型。

**发布日期**：2026-09-25

### 新功能

- **模型级采样参数**：每个模型可单独设置温度核采样最大输出，不受供应商限制。
- **继承覆盖显示**：采样参数未覆盖时标注继承供应商默认，已覆盖时高亮显示。
- **一键恢复默认**：一键清除模型级采样参数覆盖，回归供应商默认值。
- **上限自动校验**：Max Tokens覆盖值自动校验，确保不超过模型输出上限。
- **模型智能排序**：选识图模型时支持识图的排前面，不兼容的醒目提示。
- **压缩模型排序**：压缩模型按上下文窗口大小降序排列，大上下文优先选用。
- **能力标签预览**：默认模型列表右侧展示能力标签预览，选择时一目了然。
- **搜索双路匹配**：搜索同时匹配模型名称与供应商名称，查找模型更快。
- **弹窗关闭按钮**：模型选择弹窗增加关闭按钮，空状态增加引导提示。

### 改进

- **图标化标签**：默认模型页统一使用图标化能力标签，配点击文字说明与上下文双尺度。
- **模型行信息丰富**：模型行信息更丰富，展示模型名供应商描述与能力标签。
- **参数覆盖标注**：供应商编辑页高级参数标注默认值，模型可单独覆盖。
- **压缩图标更换**：压缩模型图标更换为新样式，语义表达更加清晰准确。
- **跟随对话图标**：跟随对话选项增加专属图标标识，视觉识别更加直观。

### 修复

- **删除清理参数**：删除供应商时自动清理所有关联模型的采样参数配置，避免残留。
- **参数严格隔离**：模型级采样参数修改不影响供应商级默认配置，两者严格隔离。
