# MiniMe-core 0.0.0.24 Version Log

本次更新全面重构操作审计页面，新增统计概览、分类筛选、搜索与CSV导出；修复零幻觉容忍设置四档描述、性能等级与枚举名显示错误，并将其迁入新增的高级设置页面；同时重构关于页并新增应用内代码浏览器。

## 新功能

- **操作审计重构**：审计页新增统计概览、分类筛选、关键词搜索、CSV导出，动作名中文化展示。
- **高级设置页**：新增高级设置页面，零幻觉容忍整体迁入，预留后续扩展位。
- **关于页重构**：关于页应用信息展示优化，新增应用内代码浏览器可直接查看源码。
- **插件体系文档**：新增完整插件体系设计文档，明确扩展机制与接口约定。

## 修复

- **ZTH档位描述**：修复零幻觉容忍四个档位描述全部显示为"严格"的严重bug。
- **ZTH性能等级**：修复三个性能等级描述全部显示为"高端"的错误。
- **ZTH枚举显示**：英文枚举名改为中文显示，即关闭/轻度/平衡/严格四档。
- **设置滚动记忆**：修复设置子页面退出后主页面滚动位置回到顶部的问题。

## 改进

- **ZTH设置加固**：新增当前状态摘要、四档参数对比、恢复默认与降档二次确认。
- **操作审计增强**：失败事件高亮、空态/错误态/加载态完善，新增清空全部功能。
- **字符串规范**：零幻觉容忍相关字符串从hash命名改为语义化命名，便于维护。
