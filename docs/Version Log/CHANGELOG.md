# Changelog

本文件记录 MiniMe-core 的用户可见变更，采用用户面向格式（见 [AGENTS.md](./AGENTS.md#发版规范最高优先级--强制约束--发版前逐条核对)）。

> **2026-09-25 格式变更**：原「三层日志规约」（用户层/开发者层/大模型层）已废弃，现统一为**用户面向唯一格式**。
> 结构：版本标题 → 100字简介 → 新功能 → 改进 → 移除 → 修复 → 安全 → 已知问题。
> 写作铁律：利益优先、平实语言、每条一个变更、单条≤一行、描述症状而非代码。

- 最新版本置顶，倒序排列。
- 日期用 ISO 8601（`YYYY-MM-DD`）。
- **破坏性变更用「注意」显著标注并说明用户需要做什么。**
- **禁止使用 emoji**：分类标题和正文保持纯文字，简洁专业。

## [0.0.0.42-rc1] - 2026-10-02

网络代理区块隔离：引入直连与代理双 OkHttpClient，按模型路由并在代理不通时自动降级；新增代理健康检测器与子模型代理调度，代理挂掉不再拖垮全部模型请求；订阅 Tab 同步重构为简洁选择列表。

### 新功能

- **代理区块隔离**：直连与代理双 OkHttpClient 实例，按模型类型路由，互不影响。
- **健康检测器**：代理每三十秒轮询探测，失败自动诊断并触发降级。
- **子模型调度**：压缩、识图等子模型默认直连，不随主模型走代理。

### 改进

- **订阅 Tab 重构**：订阅配置页由一千四百多行精简为一千一百余行，简化为选择列表。
- **OverrideCard 完善**：覆写卡片内容补全并重构布局，信息更清晰。

### 移除

- **订阅展开区**：移除订阅 Tab 下的节点列表、分组流量与测速展开区，简化交互。

### 修复

- **代理不通全挂**：模型请求时代理不通不再拖垮全部请求，自动降级直连。
- **代理绕圈子**：模型遇到代理问题时不再反复绕路，直接按健康状态选择通道。

### 新功能

- **反爬虫核心**：新增一批反检测动作，缓解网站指纹与人机校验拦截。

## [0.0.0.40-rc1] - 2026-10-01

网络代理工具全面升级：新增直接代理输入、订阅自动更新、流量统计与审计、连接诊断、节点健康监控等十二项能力，并加固 DNS 防泄露、崩溃自愈与熔断，提升代理稳定性与可控性。

### 新功能

- **直接代理输入**：新增 direct 类型，支持 socks5/http 单跳表单，自动合成最小 Clash 配置。
- **订阅自动更新**：记录上次更新时间与自动更新间隔，周期扫描并支持手动刷新。
- **流量统计**：按六十秒采样统计今日、本周与累计用量，主界面以卡片展示。
- **连接诊断**：进程、控制面、出口、DNS 四项检查，交通灯呈现并支持手动重测。
- **节点排序筛选**：支持延迟升序降序排序，按协议类型与地区关键词筛选。
- **热重载配置**：切换配置优先热重载不杀进程，失败再回退重启，切换更顺滑。
- **节点健康监控**：每十分钟测速，连续两次超时标记不可用置灰，可自动切最快节点。
- **前台服务保活**：常驻通知显示代理端口，点击回主界面，代理不被系统轻易回收。
- **端口冲突检测**：试绑端口，被占用时自动加一避让并持久化，同步路由与通知。
- **状态可视化**：顶部交通灯状态卡合并延迟与今日用量，代理状态一眼可见。
- **多实例预热**：后台预热一个独立实例，切换命中时零冷启动，减少等待。
- **流量审计日志**：连接快照对比批量落库，保留七天，支持 CSV 导出与列表查看。

### 修复

- **DNS 防泄露**：固定 fake-ip，国内 DoH 主、海外 DoH 兜底，避免 DNS 请求外泄。
- **危险键剥离**：dns、script、profile 等危险键纳入强制剥离清单，防止订阅覆写配置。
- **崩溃自愈**：mihomo 崩溃按指数退避自动重启，超限标记不可用并通知恢复中状态。
- **OkHttp 熔断**：代理连续三次连接失败时临时直连三十秒，避免代理挂掉全网瘫痪。
- **密钥加密存储**：control secret 改用加密存储，自动迁移并删除旧明文文件。
- **WebView 竞态**：只监听开关边沿并去重，避免重复设置交错导致代理状态错乱。

### 改进

- **类型安全加固**：代理配置相关字段统一类型安全访问，减少隐式类型转换风险。

## [0.0.0.39-rc1] - 2026-10-01

P3 数据层迁移完成：删除全部 Room Entity 过渡层，上层代码直接使用 V2 SQLDelight 模型，同时加固事务原子性、补全缺失索引并统一 Boolean 字段访问方式。

### 改进

- **数据层重构**：删除三十四个 Room Entity 过渡层，上层代码直接使用 V2 SQLDelight 模型，消除映射冗余。
- **事务原子性**：T2I 与 Credentials 模块多步写操作包入同一事务，避免中途失败留下不一致的中间状态。
- **索引补全**：Zth 子域补全三个缺失索引，列表与关联查询不再全表扫描。
- **类型安全**：Boolean 字段统一改用扩展属性封装，消除散落的 ==1L 数值判断。

### 已知问题

- P3 迁移为大规模重构，如遇数据异常或启动异常，请清除应用数据后重试。

## [0.0.0.38-rc2] - 2026-09-29

本次更新加固日志与诊断体系：日志写入更可靠不再丢行或重复写坏文件，卡顿、慢查询与网络异常统一汇入日志便于排查，崩溃现场记录脱敏并减轻负担，长时间使用不再无节制占用存储。

### 改进

- **日志写入加固**：重启或强杀后自动修复未及时落盘的日志，最多丢失一秒内容，不再整条记录凭空消失。
- **慢查询可见**：数据库慢查询自动写入应用日志，卡顿原因可以在日志页面直接查到。
- **卡顿联网汇入**：主线程卡顿与网络请求超时、失败记录统一写入应用日志，不再散落在各处无从查看。
- **日志清理收敛**：过期日志与崩溃现场的清理规则统一，长时间使用不再无节制占用存储。
- **崩溃现场减负**：崩溃记录只保留关键线程信息并限制历史条数，写入更快、占用更小。
- **日志等级统一**：应用日志与大模型日志共用同一档位，调整一次两级同步生效。
- **导出节流**：日志导出到公共目录改为最多十二小时一次，不再每次冷启动都刷同一份文件。
- **时间显示一致**：日志列表的日期解析与排序改用同一套规则，跨天滚动后的文件顺序不再错乱。

### 修复

- **崩溃记录脱敏**：崩溃现场写入公共目录前先做敏感信息脱敏，避免密钥或路径被完整落盘。
- **日志文件损坏修复**：修复导出与写入同时发生时可能写坏当前日志文件的问题。
- **导出内容脱敏修复**：导出时附加信息项也纳入脱敏，不再只有正文脱敏。
- **重复表头修复**：日志文件滚动切换后不再重复写入格式表头，解析工具识别更稳定。
- **丢弃提示修复**：日志过载丢弃内容时补记汇总提示，不再静默少写。
- **文件占用修复**：大模型会话日志长时间闲置自动释放文件句柄，减少长时间运行后的资源占用。

### 已知问题

- 子表外键级联删除（ON DELETE CASCADE）尚未在 schema 层补齐：当前已开启外键约束并由业务层按序删除子表保证一致，补齐需跨多库重建表结构，将在后续版本单独迁移。

## [0.0.0.38] - 2026-09-29

本次更新彻底修复数据层深度审计发现的致命与高危隐患：结构自愈与孤儿清理增加事务与护栏、备份恢复改为严格只读校验并明确跨设备失败、外键与写入模式显式生效、KV 与全文检索更健壮，大幅降低历史数据被静默清空或锁库的风险。

### 改进

- **自愈事务化**：结构自愈整段包事务、删表前比对行数，半途失败回滚可重试，不再永久丢数据。
- **清理前置护栏**：孤儿清理要求父表非空且单表删除不超阈值，避免一键清空全库。
- **备份只读校验**：恢复后走只读通道校验并比对行数，不再误触发隔离导致恢复成功却数据空。
- **跨设备明确失败**：跨设备备份恢复检测密钥不匹配即回滚并提示，不再报恢复成功。
- **写入模式生效**：打开后显式设置 WAL、同步模式并开启外键，约束真正生效。
- **连接池防半成品**：驱动先自愈成功再入缓存，失败即关闭并重试。
- **启动拒绝致命**：版本回退与密钥不匹配直接终止启动，不再吞异常继续。
- **大对象落盘**：超过阈值的二进制落盘存储，数据库只存路径，缩短写锁占用。
- **全文检索加固**：检索词包裹转义，语法错误转为可处理的异常。
- **类型安全读取**：KV 读取校验类型列，响应式观察指定 IO 线程。
- **迁移快照去重**：每进程每库只快照一次，保留更多代现场。
- **口令同源**：探测与驱动共用同一口令来源，消除假损坏漂移。

### 修复

- **线程切换修复**：多表级联删除改切 IO 线程执行，避免主线程 ANR。
- **并发激活修复**：目标激活采用 CAS 受影响行数判定，避免同会话出现两个活动目标。
- **主键追溯修复**：缺主键时用行序推导回填，保留与关联表的追溯链。
- **索引补建修复**：自愈补齐会话排序索引，避免列表全表扫描。
- **加密口令修复**：口令数组传独立副本，避免被擦除后误用空口令。
- **校验长度修复**：备份流式拷贝并校验长度，避免整库读入内存与溢出。
- **库标识一致修复**：恢复按 dbId 精确匹配，避免把 A 库备份写进 B 库。
- **版本探测修复**：未注入密钥时返回不可读而非全新库，避免静默重建。
- **空列表短路**：IN 查询入空列表直接短路，避免语义歧义。
- **阈值自洽修复**：慢查询记录与过滤共用同一阈值常量。

### 已知问题

- 子表外键级联删除（ON DELETE CASCADE）尚未在 schema 层补齐：当前已开启外键约束并由业务层按序删除子表保证一致，补齐需跨多库重建表结构，将在后续版本单独迁移。

## [0.0.0.37] - 2026-09-29

本次更新加固数据库密钥的保护机制：密钥损坏时不再生成新密钥顶替，加密迁移完成前会逐表比对数据行数，数据库标识改用与设备区域无关的显式常量；同时收窄紧急重置范围、禁止直接轮换数据库密钥，降低历史数据被静默清空的风险。

### 改进

- **密钥损坏不覆盖**：数据库密钥存在但解不开时明确报错并停止，不再生成新密钥顶替导致历史数据永久无法解密。
- **迁移数据校验**：加密迁移完成前逐表比对数据行数，对不上就中止迁移并保留原库与现场。
- **库标识统一**：数据库标识改用显式常量，不再依赖系统区域做大小写转换，避免特殊区域下密钥不匹配。

### 修复

- **紧急重置收窄**：重置凭据密钥时不再连带清除数据库密钥，避免六个库一起打不开、历史数据被清空。
- **数据库密钥禁轮换**：数据库密钥不再允许直接轮换（会让库文件立刻不可读），改由迁移流程整体重加密。
- **历史凭据仍可解**：字段密钥轮换后保留上一代密钥，轮换前保存的凭据不会被判为无效。

### 已知问题

无

## [0.0.0.36] - 2026-09-29

本次更新修复数据库无法打开时被误判为全新库的问题，现在会先自动备份原文件再隔离保留，历史数据不再被静默清空；迁移前快照改为轮转保留多代并在失败时自动回滚，同时统一加密库的打开方式、增强启动诊断信息，方便定位损坏原因。

### 改进

- **现场保留增强**：无法打开的数据库文件会自动备份并隔离保留，可事后人工恢复。
- **迁移失败自动回滚**：数据库迁移或打开失败时自动回滚到迁移前快照，避免停在半成品状态。
- **明文备份抢救**：数据库异常时自动保留加密迁移前的明文备份文件，历史数据多一条恢复途径。
- **诊断信息增强**：启动日志补充文件大小与文件头信息，便于判断是文件损坏还是密钥问题。

### 修复

- **数据保护修复**：修复数据库损坏或密钥不匹配时被当作全新库处理、导致历史数据被清空的问题。
- **快照失效修复**：修复连续启动时迁移前快照被写坏的主库覆盖的问题，现在保留最近三代现场。

### 已知问题

无
