# Changelog

本文件记录 MiniMe-core 的用户可见变更，采用用户面向格式（见 [AGENTS.md](./AGENTS.md#发版规范最高优先级--强制约束--发版前逐条核对)）。

> **2026-09-25 格式变更**：原「三层日志规约」（用户层/开发者层/大模型层）已废弃，现统一为**用户面向唯一格式**。
> 结构：版本标题 → 100字简介 → 新功能 → 改进 → 移除 → 修复 → 安全 → 已知问题。
> 写作铁律：利益优先、平实语言、每条一个变更、单条≤一行、描述症状而非代码。

- 最新版本置顶，倒序排列。
- 日期用 ISO 8601（`YYYY-MM-DD`）。
- **破坏性变更用「注意」显著标注并说明用户需要做什么。**
- **禁止使用 emoji**：分类标题和正文保持纯文字，简洁专业。

## [0.0.0.79] - 2026-10-07

应用打包器签名方案根本性重构：完全移除 apksig 库，基于 AOSP 公开标准手动实现 V2+V3 签名，彻底解决 Android 环境下签名块编码失败问题。

### 改进

- **签名方案重构**：从 apksig 库切换为手动实现 V2+V3 签名，基于 AOSP 公开标准精确构建签名块。
- **移除外部依赖**：完全移除 com.android.tools.build:apksig 依赖，避免 Android 环境下的库兼容性问题。
- **分块摘要计算**：实现 V2 签名标准的 1MB 分块 SHA256 摘要算法，符合 AOSP 规范。
- **双方案合并**：V2 和 V3 签名块合并到同一个 APK Signing Block 中，兼容 Android 7.0+ 全平台。

### 修复

- **签名编码失败**：彻底修复 apksig 库在 Android 环境下持续报 "Failed to encode signature block" 的根本性兼容问题。

### 已知问题

- 当前实现不包含 V1（JAR 签名），最低支持 Android 7.0（API 24）。如需兼容 Android 6.0 及以下，将在后续版本添加 V1 签名。

## [0.0.0.78] - 2026-10-07

应用打包器签名与界面全面优化：APK 升级为 V1+V2+V3 完整官方签名，项目列表和详情页统一使用设计系统组件。

### 改进

- **完整签名方案**：APK 签名从 V1+V2 升级为 V1+V2+V3 完整官方签名，兼容全平台。
- **显式版本指定**：签名时显式指定 minSdkVersion，避免从修改后的 manifest 自动读取失败。
- **提供者顺序优化**：签名时将系统默认安全提供者置首，BouncyCastle 移至末尾避免编码冲突。
- **列表界面美化**：项目列表页使用统一顶栏和卡片组件，重构卡片布局与操作按钮样式。
- **详情顶栏统一**：项目详情页顶栏替换为统一 AppTopAppBar 组件，保持全局视觉一致。

### 修复

- **签名编码失败**：修复 apksig 库因安全提供者顺序和 minSdkVersion 读取导致的签名块编码异常。
