# Changelog

本文件记录 MiniMe-core 的用户可见变更，采用用户面向格式（见 [AGENTS.md](./AGENTS.md#发版规范最高优先级--强制约束--发版前逐条核对)）。

> **2026-09-25 格式变更**：原「三层日志规约」（用户层/开发者层/大模型层）已废弃，现统一为**用户面向唯一格式**。
> 结构：版本标题 → 100字简介 → 新功能 → 改进 → 移除 → 修复 → 安全 → 已知问题。
> 写作铁律：利益优先、平实语言、每条一个变更、单条≤一行、描述症状而非代码。

- 最新版本置顶，倒序排列。
- 日期用 ISO 8601（`YYYY-MM-DD`）。
- **破坏性变更用「注意」显著标注并说明用户需要做什么。**
- **禁止使用 emoji**：分类标题和正文保持纯文字，简洁专业。

## [0.0.1.6] - 2026-10-18

本版本让对话与内置浏览器都更可靠：流式回复不再双气泡、代码块不跳动，消息长按即可复制、分享、朗读；浏览器补齐登录、全屏、拨号等网页能力，加载失败有明确提示。

### 新功能

- **消息长按操作**：长按任意消息可重新生成、删除、分享或朗读，朗读可随时停止。
- **网页登录弹窗**：需要账号密码的网页会弹出登录框，输入后正常进入，不再卡在空白页。
- **链接交给对应应用**：网页中的电话、邮件、短信、地图、应用市场链接由对应应用打开。
- **视频全屏播放**：网页视频可进入全屏播放，按返回键或按钮退出，画面不再被裁切。

### 改进

- **流式代码不跳动**：回复生成过程中代码块到达闭合标记时不再整块重排，未闭合时按半截稳定显示。
- **流式高亮更稳定**：只对已稳定的代码前缀高亮，长代码不再随生成逐字闪动。
- **工具名称说人话**：AI 调用工具时显示中文摘要，原始名称以小字附在下方。
- **半截链接不误触**：生成到一半的网址先按纯文本显示，补全后才可点击。
- **网页符号正常显示**：正文中的网页特殊符号正确解码显示，代码片段逐字保留不改动。
- **代码块排版统一**：代码块统一从左到右排列，制表符按 4 空格展开，两处查看效果一致。
- **按钮点击区扩大**：消息操作按钮点击区域扩至标准尺寸，图标大小不变，更容易点中。
- **图标尺寸统一**：对话页各类图标尺寸按统一规范绘制，视觉更一致。
- **滚动按钮更轻量**：回到底部等按钮改为贴边半透明胶囊，停止操作 3 秒自动淡出，不再遮挡内容。
- **分页加载不跳位**：加载更早的消息后仍停留在原位置，不再突然跳回顶部。
- **AI 代填输入框**：AI 操作浏览器时，网页弹出的输入对话框可代填内容后确认。
- **远端仓库可指定目录**：远端仓库操作可限定在指定目录内进行，多项目场景不再互相干扰。
- **凭据问题先诊断**：远端操作缺少凭据时先诊断再提示缺什么，不再直接失败。

### 修复

- **回复不再双气泡**：流式输出时同一条回复不再同时出现两个气泡，生成结束后自然合并为一条。
- **停止生成不丢内容**：中途停止生成时，已产生的工具结果与正文完整保留，不再只剩半截。
- **消息链接可点击**：点击已保存消息中的链接会用浏览器打开或给出提示，不再无声无息。
- **网页下拉能选择**：网页里的下拉选择框正常弹出选项列表，不再点击毫无反应。
- **新窗口正常打开**：网页中的新窗口链接正常打开，恶意弹窗仍会被拦截。
- **网页输入框恢复**：网页弹出输入对话框时显示输入框，确认后内容正确返回网页。
- **崩溃网页可恢复**：网页渲染进程崩溃后自动重建当前标签并重新加载，不再整页卡死。
- **加载失败有提示**：网页打不开时显示错误说明与重试按钮，不再只剩一片白屏。

### 安全

- **危险网页先拦截**：开启安全浏览后，已知恶意网页在打开前即被拦截，降低中毒风险。
- **权限请求不滥用**：网页请求摄像头、麦克风等敏感权限时明确拒绝，不再无限等待。
- **定位仅当次授权**：网页请求定位时临时授予，刷新或离开后即失效，不留存授权记录。
- **网页跟踪拦截**：隐私盾牌开启后，第三方网页的跟踪 Cookie 一并拦截，与设置保持一致。

## [0.0.1.5] - 2026-10-17

本版本聚焦对话可靠性与工具菜单整理：切换模型、应用被回收后的对话中断均已修复，新增远端仓库管理与浏览器操作卡片；侧边栏入口精简、图标风格统一，长对话跳转与回到底部按钮重新设计。

### 新功能

- **浏览器操作看得见**：AI 操作浏览器时，对话会显示打开网页、点击、输入等动作卡片，需要你操作时说明。
- **远端仓库可直接管理**：对话里可拉取、推送远端仓库与版本 tag，推送前检查提交信息，凭据不经 AI。

### 改进

- **远端操作重试更快**：拉取、推送、克隆的等待时间延长，大仓库不再轻易中断；缺少凭据时立即给出明确提示。
- **侧边栏瘦身**：右侧工具菜单删除无实际功能的入口，「版本控制」更名「Git 管理」，菜单更清爽。
- **菜单图标统一风格**：右侧工具菜单图标改为与左侧抽屉一致的设计，同色系入口一目了然，点击区域也更大。
- **长对话跳转更顺手**：拉到中段后，新按钮可一键跳回上一条你发的消息；回到底部按钮重新设计，取消未读数。

### 修复

- **中断不再无声无息**：应用切后台被系统回收后，重开对话时最后一条消息会标注已中断，不再看到半截回复。
- **回复气泡不再空白**：极少数情况下回复只剩一个空白气泡，实际内容为不可见字符，现已修复。
- **PHP 高亮恢复**：PHP 文件在代码阅读器与编辑器中不再整篇纯白，类名、函数、注释等正常着色。
- **多语言高亮一并修复**：HTML、Ruby、Markdown 等语言高亮异常同步修复。
- **本地网页背景图恢复**：自己部署的网页中的背景图片等资源不再被误拦截，与系统浏览器显示一致。
- **底部地址栏不再消失**：将地址栏切换到屏幕底部位置后，地址栏与底部工具条稳定显示，不再整体消失。
- **隐私盾牌不再挡网页**：网页右上角的隐私盾牌收入「更多」菜单，不再挡住网页内容，菜单同时显示拦截计数。
- **切换模型立即可用**：对话中切换到其他供应商的模型后不再被拒收，立即可用，新对话也正确使用新模型。
- **新会话默认模型正确**：新建会话时按「新会话默认模型」设置绑定供应商与模型，不再回退到全局激活的供应商。
- **浏览器实时预览恢复**：AI 操作浏览器期间，右下角悬浮的实时画面预览不再空白，首帧生成前显示等待提示。

## [0.0.1.4] - 2026-10-15

网络波动不再打断对话：请求失败自动重试，慢回复等待更久；错误提示改为大白话，断网、超时、限流、密钥失效等原因分别说明，日志同时记录失败分类便于排查。弹出菜单的阴影与开关细节同步修正。

### 改进

- **失败自动重试**：网络瞬时抖动导致请求失败时自动重试两次，不再一断线就中断对话。
- **慢回复等待更久**：模型思考时间较长时的等待延长至60秒，长回复不再被误判为无响应。
- **错误提示说人话**：连接中断、域名解析失败、连接超时、证书错误、连接被拒、请求过于频繁、额度不足、密钥失效、服务端故障等原因分别给出对应说明和应对建议，不再只显示一句英文原文。
- **失败原因可追溯**：日志中记录每次失败的供应商、模型、会话与原因分类，反馈问题更有依据。

### 修复

- **断网不再发无效请求**：设备没有可用网络时直接提示当前离线，不再反复发起必然失败的请求、也不再显示难懂的连接错误。
- **弹出菜单阴影不再发黑**：各类下拉菜单边缘的投影改为柔和的浅灰色，不再出现一圈生硬的黑色边框。
- **更多菜单开关恢复正常比例**：浏览器更多菜单中的无痕模式、桌面版网页开关恢复正常大小与比例，不再显示为变形的小药丸。
- **「检查元素」改用代码图标**：浏览器更多菜单的「检查元素」项改用代码图标，与功能含义相符。

## [0.0.1.3] - 2026-10-15

长对话与长输出的内存占用大幅下降，长时间连续对话不再轻易闪退；崩溃前的日志会同步写入文件，闪退后可查到崩溃前的记录，定位问题不再无从下手。

### 改进

- **长对话更稳**：长时间连续对话与大段输出的内存占用显著降低，不再轻易因内存不足闪退。
- **流式渲染更顺**：回复内容的渲染改为按需执行，长回复滚动与打字过程更加流畅。
- **长代码块不卡**：大段代码的显示开销明显下降，包含长代码的回复不再长时间卡顿。

### 修复

- **崩溃留痕**：崩溃前最近的应用日志现在会同步写入文件，闪退后可查到崩溃前的记录。
- **内存告警留痕**：系统内存不足时会记录内存状态并主动释放缓存，便于定位无日志闪退。
- **卡顿可追溯**：应用无响应的监控在正式版同样生效并写入日志，卡死不再无迹可寻。

### 已知问题

- **统一尚未全覆盖**：部分设置与终端界面仍为原有样式，样式统一将在后续版本继续推进。

## [0.0.1.2] - 2026-10-14

设置与终端交互体验统一整改：不可逆操作执行前增加确认、安装过程可中止，远程同步与图片生成多项设置从只存不生效修复为真实生效，并补齐安全警示。

### 新功能

- **安装可中止**：功能包安装中途可按停止键取消，不必等待其自然结束。

### 改进

- **高危操作确认**：卸载功能包、重启容器、导出凭据等不可逆操作，执行前均弹出确认，防止误触。
- **复制有反馈**：复制代码或设备信息后按钮显示对勾，约一秒半后恢复，复制结果一目了然。
- **设置控件统一**：开关、滑块、信息行、可折叠分区的行高、分割线与交互效果保持一致，设置页观感更整齐。
- **弹窗样式统一**：提示与确认弹窗版式统一，按钮层级和操作区不再各不相同。

### 修复

- **审批串会话**：审批列表只显示当前会话的待审批项，不再混入其他会话内容。
- **英文包数显示**：安装摘要按包数正确显示英文单复数，一个包时不再显示 packages。
- **月度额度生效**：图片生成月度额度此前只保存不生效，现按当月用量真正限额，超额即拒绝。
- **同步方向生效**：仅上传、仅下载等方向设置现在真正约束同步，不再被同步引擎忽略。
- **冲突策略生效**：同名文件冲突时的覆盖、跳过、重命名策略现在真正生效。
- **自动同步生效**：自动同步间隔现在按周期真实执行，应用重启后自动续跑。

### 安全

- **远程暴露警示**：开放 MCP 服务前弹出确认，明确局域网暴露与令牌明文传输风险。
- **日志导出提示**：导出日志前提示文件写入公共下载目录、可能被其他应用读取。
- **签名密钥加固**：打包应用的签名密钥加强保管，降低被他人冒名签名的风险。

### 已知问题

- **统一尚未全覆盖**：部分设置与终端界面仍为原有样式，样式统一将在后续版本继续推进。

## [0.0.1.1] - 2026-10-13

启动动画全面修复与增强：原生层主题注入解决紫色闪烁，新增图片/纯色/HTML 三种启动模式，项目配置统一收敛到 .minime/ 目录并支持存量自动迁移，文件浏览器新增隐藏文件开关。

### 新功能

- **启动动画三模式**：支持图片（同图原生+H5衔接）、纯色（背景色+三点跳动加载）、HTML（用户自定义启动页+Bridge回调）三种模式。
- **HTML 启动页 Bridge**：自定义 splash.html 可调用 window.minimeSplash.finish() 跳转，内置超时兜底自动进入主页。
- **.minime 配置目录**：项目配置统一收敛到 .minime/ 目录（config/icon/splash/build），项目根目录更整洁。
- **隐藏文件开关**：源文件浏览器新增眼睛图标按钮，切换是否显示 .minime/ 等以点开头的隐藏文件。

### 改进

- **存量项目自动迁移**：打开旧项目时自动将根目录 config.json/icon.png/splash.png 迁移到 .minime/，旧文件留档为 .bak，界面提示迁移结果。
- **构建产物统一目录**：APK 构建产物统一输出到 .minime/build/，不再散落在项目根目录。
- **启动图原生注入**：构建时修改 resources.arsc 主题 windowBackground，图片模式指向启动图位图，纯色模式改写颜色值，点击图标即见启动画面。

### 修复

- **启动紫色闪烁**：修复原生主题 windowBackground 未注入用户启动图、始终显示紫色背景的问题，实现点击图标到 WebView 首帧零白屏衔接。
- **splash 首帧闪烁**：修复 splash.html 入场动画前强制设置 opacity=1 导致首帧闪烁的问题，改为纯 CSS 动画从透明渐入。

### 已知问题

- 图标/启动图选择器的落盘目录暂未切换到 .minime/，仍保存到项目根目录，建议真机回归后统一调整。
- HTML 模式下用户自定义 splash.html 的样式与原生 windowBackground 的像素级对齐需用户自行保证。

## [0.0.1.0] - 2026-10-12

里程碑版本：应用打包器从无到有并历经多轮修复达到生产可用，模板容器完成 WebView 内核深度优化与可配置启动动画零白屏衔接，主应用新增右侧边栏收纳功能入口，同步完成架构分层重构与多项安全加固。

### 新功能

- **应用打包器**：支持在手机端将 HTML 项目打包为 APK，包含项目管理、完整构建引擎、实时日志与结果验证。
- **源文件管理**：目录树浏览、新建/重命名/删除文件，点击文件直接进入可编辑代码编辑器。
- **代码编辑器**：独立页面代码查看与编辑，支持语法高亮、未保存修改确认、定时自动保存。
- **更换应用图标**：从相册选择图片作为应用图标，构建时自动替换，更换后预览即时刷新。
- **构建流程弹窗**：底部弹窗展示步骤流程、实时日志、构建结果与 APK 分析信息，失败可重试。
- **APK 分析报告**：构建成功后自动分析 APK，展示包名、版本、权限、签名、组件统计等信息。
- **项目配置文件**：每个项目配置独立存储为 project.json，分组结构支持原子写入与旧项目自动迁移。
- **基本信息内联编辑**：应用名称、包名、版本号直接常驻可编辑，停止输入 500 毫秒后自动保存。
- **可配置启动动画**：支持自定义启动图、时长（500-5000ms）、过渡效果（淡出/缩放/上滑/溶解）、背景色、点击跳过。
- **零白屏衔接**：主题位图加 WebView 透明首帧加 splash.html 同图同色三层像素级衔接，启动无闪烁。
- **右侧边栏**：收纳终端、浏览器、打包器、Git、设置等功能入口，右滑入出加半透明遮罩，宽屏适配。
- **权限管理**：配置页新增网络、存储、设备、位置四大类共 13 项权限分组开关。
- **Bridge 能力开关**：JS Bridge 五大模块（UI/设备/文件/网络/数据）可独立开关，按需启用。
- **显示启动设置**：沉浸模式、屏幕方向、状态栏颜色、启动页开关、启动延迟、全屏启动等配置项。
- **资源编辑器**：新增 ArscEditor 修改 resources.arsc 全局字符串池，支持应用名称等资源原地替换。

### 改进

- **WebView 内核优化**：Application 期后台线程预热内核，首帧上屏后再建 WebView，未声明网络时断网，冷启动大幅提速。
- **渲染进程恢复**：实现 onRenderProcessGone，渲染进程崩溃后自动销毁旧实例并重建，避免白屏不可用。
- **资源不压缩直读**：网页文本与字体资源在 APK 中以不压缩方式存储，AssetManager 直接映射读取，省去运行时 inflate。
- **Bridge 健壮性**：callbackId/eventName 严格转义防注入，新增调用耗时埋点与 JS 错误上报接口。
- **CSP 安全注入**：shouldInterceptRequest 对 HTML 注入 Content-Security-Policy，允许内联但禁止 eval，收敛外联面。
