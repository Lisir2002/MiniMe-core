# Changelog

本文件记录 MiniMe-core 的用户可见变更，采用用户面向格式（见 [AGENTS.md](./AGENTS.md#发版规范最高优先级--强制约束--发版前逐条核对)）。

> **2026-09-25 格式变更**：原「三层日志规约」（用户层/开发者层/大模型层）已废弃，现统一为**用户面向唯一格式**。
> 结构：版本标题 → 100字简介 → 新功能 → 改进 → 移除 → 修复 → 安全 → 已知问题。
> 写作铁律：利益优先、平实语言、每条一个变更、单条≤一行、描述症状而非代码。

- 最新版本置顶，倒序排列。
- 日期用 ISO 8601（`YYYY-MM-DD`）。
- **破坏性变更用「注意」显著标注并说明用户需要做什么。**
- **禁止使用 emoji**：分类标题和正文保持纯文字，简洁专业。

## [0.0.0.22] - 2026-09-26

本次更新新增独立版本更新中心，支持最新版本与历史版本双 Tab 浏览和下载；紧急修复数据库加密迁移失败与凭据解密崩溃两个关键问题；重构备份还原页面提升恢复安全性；修复开发者选项无法解锁的问题；同时移除设置导出导入与变更历史功能。

### 新功能

- **版本更新**：新增独立版本更新中心，双 Tab 浏览最新版本与历史版本，支持完整更新日志、页面内下载进度和旧版回退安装。
- **启动检查**：应用启动时静默检查新版本，有更新时在入口显示红点提示，不弹窗打扰，可在设置中关闭。

### 修复

- **加密迁移**：修复 sqlcipher_export 结果行未消费导致的 another row available 错误，逻辑版本升级至 v3 自动重置历史失败状态。
- **凭据解密**：修复 V2 解密失败时抛出异常导致应用崩溃的问题，改为降级返回空串并记录密文长度与密钥状态日志。
- **开发者选项**：修复连续点击版本号无法解锁开发者选项的问题，新增点击次数提示和解锁状态持久化，解锁后显示入口。

### 移除

- **设置导出**：移除设置导出导入功能，不再支持按分类导出、加密备份和冲突合并操作。
- **变更历史**：移除设置变更历史与回滚功能，不再自动记录配置变更和单条批量回滚。

### 改进

- **备份还原**：备份与还原页全面重构为四区卡片布局，恢复流程增加安全点校验和完整性验证机制。

### 已知问题

无

## [0.0.0.21] - 2026-09-26

本次更新全面重构容器文件管理器，新增设置搜索、导出导入、变更历史、开发者选项等六项设置增强，落地启动测量、崩溃捕获、数据库优化等七项性能稳定性提升，修复加密数据库迁移异常。

### 新功能

- **文件管理器**：容器文件管理全面重构，支持类型识别、网格视图、面包屑导航和操作面板。
- **设置搜索**：设置页支持拼音搜索、模糊匹配和错别字容忍，结果高亮显示。
- **设置导出**：设置支持按分类导出导入，统一格式，冲突可选择覆盖或保留，支持加密。
- **变更历史**：设置变更自动记录，支持按时间查看历史，单条或批量回滚配置。
- **设置导航**：设置首页重新设计，常用设置置顶，子分组折叠，页面切换带动画。
- **即时反馈**：设置变更即时提示生效，需重启项显示标记，危险操作二次确认。
- **开发者选项**：连续点击版本号解锁，含性能监控、日志查看、数据库浏览和调试开关。
- **崩溃捕获**：异常退出自动捕获信息，下次启动提示查看报告，可查看崩溃历史。
- **网络监控**：调试模式记录网络请求历史，显示地址、状态码、耗时，支持查看详情。

### 改进

- **启动动画**：粒子聚合增加发光辉光，玻璃碎片增加半透明材质、高光边缘和3D翻转。
- **启动性能**：新增启动耗时测量，非关键组件延迟并行初始化，首屏渲染优化。
- **内存管理**：新增内存监控，定期采样使用情况，高占用时自动回收，可查看详情。
- **列表性能**：对话、设置、文件列表优化渲染性能，稳定标识减少重组。
- **数据库优化**：新增会话列表排序索引，定期清理过期数据和临时缓存。
- **电池优化**：新增电池优化开关，低电量时降低动画质量和后台轮询。
- **架构细节优化**：应用架构细节优化，提高产品质量，优化用户体验。

### 移除

- **对话搜索**：移除对话内全文搜索功能，包括搜索栏、匹配高亮和搜索历史。
- **对话导出**：移除对话导出功能，不再支持Markdown、纯文本、JSON格式导出和分享。
- **多模型对比**：移除多模型对比模式，不再支持分屏同时回答、评分和采纳。

### 修复

- **加密迁移**：修复加密数据库迁移失败导致的初始化异常，迁移改用整库导出方案。
- **命令解析**：修复含输出合并符的命令被错误识别为数字工具的问题，清理无效授权记录。

### 已知问题

## [0.0.0.20] - 2026-09-25

本次更新全面升级四大核心模块：启动动画粒子聚合清晰可读并支持风格切换，AI对话新增富文本渲染、对话搜索、消息操作、模板导出等九项增强，终端容器新增文件管理、分屏多会话、快捷命令、资源监控等八项能力，浏览器新增下载管理、密码管理、广告拦截、开发者工具等功能。

### 新功能

- **启动动画**：粒子聚合成MiniMe文字，玻璃破碎3D效果，性能自适应降级，支持风格切换。
- **富文本渲染**：AI回复支持代码高亮、表格、列表、引用，代码块带语言标签和复制按钮。
- **对话搜索**：对话内全文搜索消息，匹配结果高亮，支持上下导航定位，保留搜索历史。
- **消息操作**：长按消息弹出操作面板，支持复制、重生成、编辑、收藏、分享、删除。
- **流式优化**：AI回复智能滚动跟随，上滑显示新消息按钮，打字光标动画，可停止。
- **模型切换**：切换模型时选择保留上下文或清空新对话，显示token估算和窗口占用率。
- **用量可视化**：顶栏显示token用量和窗口占比进度条，使用率超百分之八十变红警告。
- **对话模板**：内置编程、写作、分析、创意四类预设提示词，支持自定义模板和变量。
- **对话导出**：支持Markdown、纯文本、JSON三种格式导出对话，可分享或保存文件。
- **多模型对比**：对比模式最多三个模型同时回答，分屏独立滚动，可评分并采纳回答。
- **文件管理**：容器内文件管理器，支持浏览、编辑、查看、复制剪切、重命名删除、导入导出。
- **终端分屏**：多标签终端会话，支持上下分屏显示，分隔线可拖动，会话状态保留。
- **快捷命令**：常用命令快捷面板，六分类内置命令，支持自定义命令和变量输入。
- **资源监控**：容器CPU、内存、存储、进程实时监控，两秒刷新，点击展开详细指标。
- **终端主题**：内置六套终端配色主题，支持自定义字体大小、行高、光标样式，可预览。
- **密钥管理**：支持生成Ed25519和RSA密钥，加密存储私钥，公钥一键复制。
- **容器快照**：容器快照创建与恢复，最多保留五个自动清理，恢复前自动备份可回滚。
- **标签管理**：浏览器标签长按菜单，支持关闭此标签、关闭其他、全部关闭，网格管理。
- **下载管理**：下载进度实时显示速度和百分比，支持暂停继续取消，通知栏显示。
- **密码管理**：密码加密存储，访问需生物识别，自动填充网页登录表单，强度评分。
- **广告拦截**：内置广告和跟踪器拦截，地址栏盾牌显示拦截数量，可自定义规则。
- **开发者工具**：网页控制台日志、网络请求列表、DOM元素查看，支持执行JavaScript。
- **手势操作**：网页边缘滑动后退前进，页面顶部下拉刷新，双指捏合缩放，三档可调。

### 改进

- **容器重启**：重启容器保留所有数据和配置，重置容器清除根文件系统恢复初始态。
- **切换镜像**：点击切换镜像弹出选择列表，当前镜像高亮标记，运行中切换需确认。
- **镜像源设置**：镜像源支持自定义地址输入，预设多个常用镜像源，保存后立即生效。
- **容器卡片**：容器状态卡片移除粗黑边框，改用柔和阴影，与镜像列表卡片风格统一。

### 修复

- **启动动画**：修复粒子聚合成一团墨迹文字不可读问题，移除旧版灰色胶囊残留。
- **标签栏修复**：修复浏览器标签栏被系统状态栏遮挡，正确处理状态栏和导航栏间距。
- **地址栏修复**：修复地址栏提示文字过长被截断的问题，简化为输入网址或搜索。
- **全局残留**：彻底移除旧版启动动画图标和主题配置，冷启动无图标闪现。
